# 执行剩余 Code Review 整改用例

目标：逐项执行当前 92 条 NOT RUN 及 33 条 PARTIAL 的未覆盖场景，记录真实结果并修复执行中发现的核心缺陷。
规模：large。用户要求主线程独立完成，授权原话：“不要开子线程，你自己完成”；当前请求：“执行剩余用例”。
include：相关模块的测试代码、为用例失败所必需的最小业务修复、.ai/docs/20260925-test-remaining/、用例总册当前结果链接、本 TASK/State。
exclude：生产数据、共享开发库写入、未经授权的生产迁移与部署、非相关重构。临时 Docker 测试资源按唯一名称创建并清理。
需求与程序设计沿用 .ai/docs/20260924-code-review-design/CR-01～CR-07 及数据库章节；测试预期沿用 .ai/docs/20260924-code-review-testcases/。本轮新增隔离测试环境与逐项结果，不把旧结果当作新执行证据。
完成标准：对 136 条均给出当前状态和本轮证据；能隔离执行的用例实际执行；未执行项注明具体环境依赖；发现 FAIL 后保留复现与修复证据；相称回归与 State 校验通过。
