# 回归用例

使用真实临时文件，均由 src/sync/sync-recovery.test.cjs 执行：
1. TC04-30：markWritten 屏障改写源，恢复位置须包含最新字节。
2. 打开句柄跨移动继续写入；若平台拒绝移动则源保持。
3. 遍历后新增目录文件，整体移动并登记清单。
4. 注入 EBUSY，源保留；取消注入后同事件重试成功。
5. 注入设备号差异，恢复目录选择同步根旁。
6. 实际临时目录与工作区跨卷，最新字节移动保全。
7. 注入 EXDEV，源保留，无复制删除回退。
8. pending 目标与新源同时存在，拒绝覆盖双方。
9. complete 事件重放，新出现同名源保持。
10. 恢复目录与其他同步根重叠，拒绝操作。
11. 移动后清单提交失败，原件仍在恢复目录。

Java：真实重建服务编排生成 fixture 的大 ID 请求；空集合不得访问 ES/Storage。构建、类型检查及既有测试作为回归门禁。
