# 需求：st-cloud 代码优化（按 Codex 执行任务）

## 背景
《st-cloud-full-code-review.md》给出全量 Review：总体架构良好（8/10），但存在 4 类生产级风险——文件对象模型、大规模扩展、上传一致性、并发容量控制。P1 问题 5 项，P2 优化 3 项。《st-cloud-Codex-execution-tasks.md》将优化拆为 TASK-001..006。

## 用户故事
作为云盘管理员，希望文件去重与秒传可靠，物理对象不重复存储、不误删。
作为用户，希望大文件上传稳定、并发上传不超额。
作为运维，希望事件不丢、ES 最终一致、权限计算可扩展。

## 功能范围（6 项）
- TASK-001 文件对象模型（file_object 表，去重/引用计数）
- TASK-002 上传流程状态机（INIT/UPLOADING/MERGING/STORED/FAILED + 幂等/恢复）
- TASK-003 容量并发控制（乐观锁/原子预扣）
- TASK-004 事件可靠性（Outbox + RocketMQ）
- TASK-005 权限性能（权限快照/缓存）
- TASK-006 测试体系补充

## 验收标准
- 同一物理文件仅存一份（同租户内按 MD5 去重）
- 删除文件不误删共享对象（引用计数安全）
- 并发上传超配额仅合法请求成功
- 事件不因事务提交后处理失败而丢失
- 大目录权限判定不递归遍历
- 新增测试覆盖文件/并发/权限三类
