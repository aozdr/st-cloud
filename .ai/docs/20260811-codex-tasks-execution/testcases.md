# 测试用例：st-cloud 代码优化

## 总原则
每 TASK 完成后补充对应测试；接口契约回归；`mvn -pl st-core -am` 编译 + 单测。

## TASK-001 文件对象
- 同租户同 MD5 秒传只新增引用，不重复存储
- 跨租户同 MD5 各自独立对象
- 删除最后一个引用才删除物理对象；引用未归零不误删
- 版本恢复引用计数正确

## TASK-002 上传状态机
- 分片上传成功路径、失败恢复、重复 merge 幂等、abort 清理

## TASK-003 容量并发
- 多线程同时上传超配额：仅合法请求成功
- 配额扣减不出现负数

## TASK-004 事件
- 事务回滚不产生事件；MQ 失败可重投；消费幂等
- ES 最终一致（重投后索引存在）

## TASK-005 权限
- 大目录权限判定命中缓存，不递归
- 权限变更后缓存失效
