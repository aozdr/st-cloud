# 实施设计（定版 env-design-r1）

1. 保存初始 Git 状态/冲突副本；JDBC 只读读取本机 MySQL 身份、结构、索引和版本，检查配置与依赖。
2. 整合冲突：新写入用 UUID 持久候选，提交失败只放弃候选延迟 GC；H2 合并全部表，保留两侧用例；Sidebar 合并权限/配额与 UI。
3. 独立桌面任务修复 B01，补真实 HTTP 受控轮换；后端可运行时验证 Redis 轮换。
4. 新递增 SQL 补必要结构和索引幂等；H2 通过后运行 compare-schema，执行缺少开发迁移、登记唯一版本，再比较退出 0。已执行脚本不盲目重放。
5. V02–V06/O01–O04 按现有专项补当前证据，需要时新增并发用例。O02 仅修改确认允许的默认路径，保留真实漏设告警；O03 增适用健康检查。O05 不删除资源。
6. 主线程串行完成 Maven 测试/打包、桌面回归、Web 构建；独立审查后修复并重验受影响项。

V06 新复现后的实施细化：真实 MySQL 4 项证实锁前权限/状态快照可继续使用。团队回收写入按现有团队成员写路径先锁 team_space，再锁根节点，然后重读当前成员权限与状态；个人节点直接锁节点。清空与定时清理也锁后重判状态，数据库事务中仍不执行 S3。保持 API 与拥有者/管理员规则，属于既定整改范围，无新增未决决策。

目标、用户、场景与边界见 requirement.md。HTTP 响应不变，新增 IPC 兼容旧调用；开发凭据继续接受环境变量覆盖，生产密钥规则保留。数据库只补结构、保留行与安全版本。连接失败/SQL 失败直接报告，不重启身份不明进程。旧刷新/换服/退出与新会话隔离；并发用例释放锁和连接。现有暂存、审计记录保留。未决事项：无。
