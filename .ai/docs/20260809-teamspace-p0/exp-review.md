# UI/UX 设计文档：团队空间 P0 基础协作补齐

> 归属 exitCriteria: EXP_DESIGN（依赖 REQ_ANALYSIS）
> 关联需求文档: `.ai/docs/20260809-teamspace-p0/requirement.md`
> 设计系统遵循: `.ai/knowledge/ui-design-system.md`，沿用现有 Tailwind 设计令牌（bg-surface / border-border / text-fg / text-muted / bg-primary-600 等）

## 1. 设计概述

P0 在不改变团队空间整体页面框架的前提下，增强现有组件并新增轻量页面。设计原则：

- **复用优先**：设置弹窗、成员弹窗在现有结构上扩展，不新建弹窗体系
- **最小侵入**：文件浏览器（FileBrowser）组件不改动，动态 Tab 在页面层级新增
- **一致性**：沿用现有按钮/表单/弹窗视觉规范，无新增设计令牌

## 2. 页面改动清单

| 页面 | 改动类型 | 说明 |
|------|----------|------|
| TeamSpacePage | 扩展 | 设置弹窗补全表单、新增动态 Tab、成员弹窗新增邀请链接+退出/移交 |
| TeamInvitePage | 新增 | 邀请链接落地页 |
| App.tsx | 新增路由 | `/team/invite/:code` |

## 3. 详细设计

**现状**：设置弹窗仅含存储配额输入 + 单位选择。

**改动**：弹窗改为分区表单，自上而下：

```

│  ┌──────────────────────────────┐   │
│  │ 空间名称 *                    │   │
│  │ [产品研发组            ]      │   │
│  └──────────────────────────────┘   │
│  ┌──────────────────────────────┐   │
│  │ 空间描述                      │   │
│  │ [研发团队共享空间       ]     │   │
│  └──────────────────────────────┘   │

│  [📁][📂][🚀][💡][🎨][⚙️][🏢][📊] │  ← emoji 预设网格，选中高亮
│                                      │

- 图标：预设 24 个常用 emoji 网格（4x6），点击选中，当前 icon 高亮（`ring-2 ring-primary-500`）

│  ┌───────────────────────────────────────┐  │
│  │ 🔗 /team/invite/aB3x...  查看者·7天    │  │
│  │   创建于 08-09 14:30    [复制] [撤销]  │  │
│  ├───────────────────────────────────────┤  │
│  │ 🔗 /team/invite/kF9m...  编辑者·永久   │  │
│  │   创建于 08-08 10:15    [复制] [撤销]  │  │
│  └───────────────────────────────────────┘  │
│                                               │

- 生成链接：选角色 + 有效期 -> 点击生成 -> 新链接出现在列表顶部
- 复制：点击复制完整 URL（`window.location.origin + /team/invite/{code}`）到剪贴板，Toast 提示
- 撤销：二次确认后调 DELETE，链接行淡出消失
- 过期链接显示灰色「已过期」标签，不可复制

│                                                │

切换到「动态」Tab 后：

```
┌──────────────────────────────────────────────┐
│  筛选: [全部▼]                                │
├──────────────────────────────────────────────┤
│                                                │
│  [头像] 张三 上传了文件 设计稿_v2.fig         │
│         2 分钟前                              │
│                                                │

│                                                │
│  [头像] 张三 删除了文件夹 旧资料               │

│                                                │
│  [头像] 系统修改了空间设置                     │

- 活动项：头像（圆形，首字母回退）+ 昵称 + 操作描述 + 目标名称 + 相对时间
- 操作描述文案映射：
  - FILE_UPLOAD -> "上传了文件"
  - FILE_DELETE -> "删除了"
  - FILE_RENAME -> "重命名了"
  - FILE_MOVE -> "移动了"
  - FOLDER_CREATE -> "创建了文件夹"
  - MEMBER_JOIN -> "加入了空间"
  - MEMBER_LEAVE -> "退出了空间"
  - MEMBER_INVITE -> "邀请了"
  - MEMBER_ROLE_CHANGE -> "修改了成员角色"
  - SPACE_UPDATE -> "修改了空间设置"
  - SPACE_TRANSFER -> "移交了空间所有权"
  - INVITE_CREATE -> "创建了邀请链接"
  - INVITE_REVOKE -> "撤销了邀请链接"
- 筛选下拉：全部 / 文件操作 / 成员操作 / 空间操作
- 相对时间：复用现有时间格式化工具，<1小时显示"x分钟前"，<24小时显示"x小时前"，否则显示日期
- 分页：滚动到底部自动加载下一页（每页 20 条）

## 4. 交互细节

- 所有弹窗沿用现有 `fixed inset-0 z-50 bg-black/50` 遮罩 + 居中卡片模式
- 按钮沿用：主操作 `btn-primary`（bg-primary-600）、次操作 `btn-secondary`
- 表单输入沿用：`px-3 py-2 text-sm bg-surface-2 rounded-md border border-border outline-none focus:border-primary-400`
- Toast 提示复用现有 `useToast`
- 动态 Tab 切换不卸载 FileBrowser（用条件渲染 + hidden 控制显隐，保持文件浏览状态）

## 5. 无障碍

- Tab 栏使用 `role="tablist"` / `role="tab"`，键盘左右切换
- 邀请链接复制按钮有 `aria-label="复制邀请链接"`
- 退出/移交确认弹窗有 `role="alertdialog"`
- emoji 图标网格每个按钮有 `aria-label`（emoji 名称）

## 6. 响应式

- 设置弹窗 `max-w-md`，移动端撑满
- 成员管理弹窗 `max-w-lg`，移动端撑满，成员列表行布局自适应
- 动态 Tab 内容移动端单列
- 邀请落地页 `max-w-sm` 居中
