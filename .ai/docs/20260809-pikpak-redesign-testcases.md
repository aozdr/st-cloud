## 1. 测试范围

阶段1 纯前端视觉系统变更：
- 蓝色主题色阶（#306eff）
- 默认浅色模式
- 侧边栏浅色化 + 淡蓝选中态
- 顶栏搜索快捷键
- 文件网格 16:9 缩略图 + 16px 圆角 + 模糊背景填充
- 文件夹优先排序开关
- brand-gradient token 化
- 编译 + 功能回归 + 双模式一致性
