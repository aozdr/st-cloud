# 收藏功能完善 - 需求文档

> 经 Grill Me 拷打分析 + 四方需求评审（产品/前端/后端/测试）后输出

## 1. 背景

收藏功能已实现基础能力（后端 toggle/list/ids 接口、前端星标图标、首页收藏区块），但存在以下体验缺口：

- **无独立收藏页面**：用户只能在首页看到最多 8 个收藏，超过部分不可见，无"查看全部"入口
- **无侧边栏入口**：侧边栏导航没有"我的收藏"链接，用户无法快速到达收藏列表
- **无收藏优先排序**：文件列表中收藏的文件不会排在前面，用户收藏后仍需在目录中翻找，收藏价值未体现
- **遗留 localStorage 收藏逻辑**：`src/lib/favorites.ts` 仍存在基于 localStorage 的旧收藏实现，与后端 API 收藏逻辑并存，需清理

## 2. 用户故事

- 作为用户，我希望在侧边栏看到"我的收藏"入口，点击进入收藏页面，查看我所有收藏的文件和文件夹
- 作为用户，我希望在收藏页面能像文件管理器一样浏览、预览、下载、取消收藏收藏的文件
- 作为用户，我希望在文件列表中收藏的文件排在前面，方便快速定位常用文件
- 作为用户，我希望收藏页面支持搜索和排序，方便在大量收藏中查找

## 3. 功能范围

### 3.1 前端需求

#### F1. 侧边栏"我的收藏"入口
- 在侧边栏 `mainNav` 中新增"我的收藏"导航项，图标使用 Star，路由 `/favorites`
- 位于"全部文件"下方、"我的分享"上方

#### F2. 收藏页面（`/favorites`）
- 新增 `FavoritesPage` 页面，复用 `FileBrowser` 组件
- 通过新增 `favoriteFileSource`（FileSource 实现）对接后端 `/favorite/list` 接口获取收藏列表
- 页面标题显示"我的收藏"
- 支持文件列表的全部操作：预览、下载、取消收藏、右键菜单
- 双击文件夹跳转到对应目录；双击文件打开预览
- 支持表格/卡片/网格三种视图切换
- 取消收藏后实时从列表移除

#### F3. 文件列表收藏优先排序
- 在 `FileBrowser` 文件列表中，收藏的文件/文件夹排在同类型内最前面
- 排序优先级：文件夹优先 > 收藏优先 > 用户选择的排序字段（名称/大小/时间）
- 前端在已排序结果基础上，将收藏项置顶（当前页内排序）

#### F4. 首页收藏区块增加"查看全部"
- 首页"我的收藏"区块标题旁增加"查看全部"链接，点击跳转 `/favorites`

#### F5. 清理遗留 localStorage 收藏逻辑
- 删除 `src/lib/favorites.ts`（已被 `store/favorites.ts` + 后端 API 替代）
- 确认无其他文件引用后移除

### 3.2 后端需求

#### B1. 收藏列表支持分页
- 现有 `/favorite/list` 返回全量列表，无分页。收藏页面需支持分页
- 新增 `GET /favorite/page?page=1&size=50` 分页接口，返回 `IPage<FileNodeVO>`
- 原 `/favorite/list` 保留（首页区块仍用全量）

#### B2. 文件列表支持收藏排序（可选，视设计评审决定）
- 评估是否需在后端 `listDirectory` 中按收藏状态排序
- **设计评审结论**：收藏数量通常较少（几十个），分页 50 条/页，前端当前页排序已足够。后端不改 listDirectory 查询，避免 JOIN 影响性能。前端在排序后置顶收藏项。

#### B3. 收藏权限校验补强
- `toggleFavorite` 时校验当前用户对目标文件节点有访问权限（owner 或租户管理员）
- 防止用户收藏无权访问的文件

## 4. 影响模块

| 层 | 模块 | 变更 |
|----|------|------|
| 后端 | st-core | FavoriteController 新增分页接口；FavoriteServiceImpl 增加分页查询 + 权限校验 |
| 前端 | 路由 | App.tsx 新增 `/favorites` 路由 |
| 前端 | 页面 | 新增 FavoritesPage.tsx |
| 前端 | 组件 | Sidebar 新增收藏导航项；FileBrowser 增加收藏排序逻辑 |
| 前端 | lib | 新增 favoriteFileSource；删除遗留 favorites.ts |
| 前端 | store | 无变更（store/favorites.ts 已满足需求） |
| 数据库 | 无变更 | file_favorite 表已存在，无需迁移 |

## 5. 风险

| 风险 | 等级 | 应对 |
|------|------|------|
| 收藏页 FileBrowser 复用兼容性 | 中 | favoriteFileSource 需适配 FileSource 接口，部分操作（新建文件夹/移动）在收藏页无意义，需禁用 |
| 前端收藏排序与后端分页冲突 | 低 | 前端仅在当前页内排序置顶，不跨页重排；设计评审确认可接受 |
| 遗留 favorites.ts 被引用 | 低 | 已确认仅 HomePage 曾引用，现已改用 store，可安全删除 |

## 6. 验收标准

### AC1. 侧边栏收藏入口
- 侧边栏显示"我的收藏"导航项，点击跳转 `/favorites`
- 折叠状态下显示图标，展开显示文字

### AC2. 收藏页面展示
- `/favorites` 页面展示所有收藏的文件和文件夹
- 支持表格/卡片/网格三种视图
- 空收藏时显示空状态提示

### AC3. 收藏页面操作
- 双击文件夹跳转到文件管理器对应目录
- 双击文件打开预览
- 右键菜单可用（取消收藏、下载、详情等）
- 取消收藏后该项从列表实时移除

### AC4. 收藏优先排序
- 文件列表中收藏项排在同类型（文件夹/文件）内最前面
- 切换排序方式（名称/大小/时间）后收藏项仍置顶
- 取消收藏后该项回到正常排序位置

### AC5. 首页"查看全部"
- 首页收藏区块有"查看全部"链接，点击跳转 `/favorites`

### AC6. 后端分页接口
- `GET /favorite/page?page=1&size=50` 返回分页结果
- 返回结构与 `/file/list` 一致（IPage<FileNodeVO>）

### AC7. 权限校验
- 用户不能收藏无权访问的文件节点
- 收藏列表只返回当前用户自己的收藏

### AC8. 遗留代码清理
- `src/lib/favorites.ts` 已删除
- 无编译错误，无运行时引用残留
