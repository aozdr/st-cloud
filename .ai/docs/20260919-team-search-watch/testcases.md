# 测试用例

- 版本：tsw-design-r1；作者：GPT-6；状态：用例设计，尚未执行。
- 测试代码由 GPT-5.6-Luna max 实现；集成测试串行运行。

基础数据：租户 A/B；A 中团队 X/Y；X 管理员、编辑者、查看者、无 view 自定义角色、仅子目录 view 成员、过期外部成员、已退出成员；个人文件属主/非属主。文件含支持正文、超 20MB、图片、隐藏父目录、回收父目录、上传中、版本变化以及多层目录。测试数据仅在测试库/临时 fixture 创建，不删除用户数据。

| 用例 | 对应验收 | 步骤与期望 |
|---|---|---|
| TC-S01 | S01 | 同团队非上传者按名称/正文检索，命中；非成员/到期成员/跨租户同 ID 输入均拒绝 |
| TC-S02 | S02 | 仅对子目录有 view 的成员检索，只返回授权节点；错误 spaceId/folderId、非目录 scope 拒绝 |
| TC-S03 | S02 | 隐藏、隐藏祖先、回收自身/祖先、未完成上传、断链/循环祖先全部不返回 |
| TC-S04 | S03 | ES 返回有权及无权命中混合，响应只含授权名称/摘要/路径，没有原始 total；撤权后新请求不可见 |
| TC-S05 | S04 | 第一批 100 个命中无权、后批可见，仍返回合法页；20+1 lookahead 不跳项；稳定数据连续页无重复 |
| TC-S06 | S04 | 修改游标、跨用户/租户复用、换词/筛选/目录、过期游标均拒绝；正常游标可续页 |
| TC-S07 | S05 | ES 抛异常显示暂不可用；扫描超预算给缩小范围提示；零命中正常空页 |
| TC-S08 | S05 | 旧文档缺身份字段不进入团队结果；MD5/路径与当前 DB 不一致不展示旧正文/路径 |
| TC-S09 | S01,S04 | 类型/大小/时间过滤生效；非法负 size/过大 size/反向范围/超长 keyword 被校验 |
| TC-S10 | S06 | 原个人搜索契约回归；团队文件夹进入正确 space 与目录，文件预览仍按团队权限 |
| TC-W01 | W01 | 关注文件和目录、重复 PUT、DELETE 两次、重新关注；唯一约束及新 watchId 正确，收藏不受影响 |
| TC-W02 | W01,W02 | 匿名、非属主、无权团队节点不能关注；本人订阅分页；失效记录清空名称/路径且仍可取消 |
| TC-W03 | W03 | 同时关注文件、父目录、祖父目录，只产生一条该 event/user 通知；不同事件各自保留 |
| TC-W04 | W03,W08 | 同事件重复捕获、重复消费及两个消费者争用同 delivery，不重复插入 notification |
| TC-W05 | W04 | 文件写事务回滚，队列和通知都不存在；上传未完成/下载/预览/收藏不产生事件 |
| TC-W06 | W04 | 新建/秒传/上传完成/解压/复制/恢复→CREATE；覆盖/文本/Office/版本恢复/同步写→UPDATE，逐入口核对一次事件 |
| TC-W07 | W04 | actor=user 不自我通知；actor 缺失不伪装 owner；他人更新通知有效订阅者 |
| TC-W08 | W05 | 重命名订阅保持；移入/移出目录只匹配当次旧/新父链，移出后下一次更新不发给旧目录订阅 |
| TC-W09 | W05 | 删除/移动目录根，直接关注后代的用户被覆盖，每用户该根事件最多一次；不跨空间匹配同名路径 |
| TC-W10 | W06 | 入队后取消，不投递；取消后重订阅同 node，新 watchId 不接收旧队列；另一个原有匹配订阅仍可生效 |
| TC-W11 | W06,W07 | 入队后退出/过期/撤权不发送细节；发送后撤权，列表与 target 响应清空细节 |
| TC-W12 | W07 | 删除通知为通用不可用；读他人 notification id 不能取目标/改已读；跨租户接口同样拒绝 |
| TC-W13 | W08 | 插入通知失败回滚整条处理；retry 退避后恢复；模拟重启重读 pending/retry；超上限标记可排查失败 |
| TC-W14 | W08 | MQ 开启/关闭均捕获订阅队列且不重复；同步原消费者行为保持 |
| TC-U01 | U01 | 375px 与桌面搜索/关注/通知可达；键盘 Enter/Space/Escape；失效状态不出现可点击无权目标 |
| TC-U02 | U01,S06 | 查询 A 未返回时切到 B，A 响应迟到不能覆盖；加载更多防双击；关注切节点不污染状态 |
| TC-E01 | E01 | SQL 首行、编号、MySQL/H2 字段一致；SchemaConsistencyTest + 迁移前后双对比（后者退出 0） |
| TC-E02 | E01 | 后端受影响模块测试、前端类型与构建；记录命令退出码、环境与未执行原因 |

测试层次：服务/控制器单元测试验证鉴权分支与 DTO；H2 集成测试验证唯一键、事务回滚、真实 mapper 与重试；ES fixture 验证索引映射及正文召回；浏览器验证真实 UI 路由和窄屏布局。Mock 测试不能替代 MySQL 双对比与 ES/浏览器实际验证。

性能观察：记录测试数据量、候选批数、总延迟及 SQL 次数；验证上限无全量无界扫描。无积压环境检查提交至通知可查询不超过 60 秒目标，结果写 testreport；未实测不得标通过。
