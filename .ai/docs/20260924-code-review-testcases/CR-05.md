# CR-05 分享额度测试用例

来源：[需求](../20260924-code-review-design/CR-05/requirement.md)、[设计](../20260924-code-review-design/CR-05/design.md)。全部 NOT RUN。创建有效分享 H，count=0，limit=1，合法提取码、下载权限、完成上传文件 F；另准备子树外文件 X。流客户端记录文件响应首字节/字节数，服务端拦截 getOutputStream、源流 close 和原子 UPDATE 结果。建议真实 MySQL、多实例集成，不能只验证最终 count。

| ID / 优先级 / 映射 | 前置条件与步骤 | 预期结果与证据 |
|---|---|---|
| TC05-01 / P0 / A05-1 | 5个独立请求通过前置校验，在占位前屏障同时释放，读取同一 H 的流。 | 最多1个请求获得并输出文件字节；其他请求在文件输出前拒绝；count=1，无重复扣减。 |
| TC05-02 / P0 / A05-2 | 两实例共用数据库，一个发 URL、其余发流，竞争剩余1次。 | 成功 URL 发放数+成功流授予数≤1；失败 URL 请求不暴露预签名地址；失败流输出文件字节为0。 |
| TC05-03 / P0 / R05-1 | 分别错误提取码/验证码、过期/禁用分享、关闭下载、缺 download 权限。 | 前置拒绝，count 不变，无文件输出/URL；不触发不必要的源流访问。 |
| TC05-04 / P0 / R05-1 | 分别请求不存在、回收站、上传未完成、分享子树外 X。 | 拒绝且不占次数，不通过可猜 nodeId 绕范围。 |
| TC05-05 / P0 / A05-3 | 前置合法，源对象打开失败；URL 路径另注入预签名生成失败。 | 均不占次数、无成功响应，不把失败视为已授予。 |
| TC05-06 / P0 / A05-3 | 成功打开源流后令额度被另一请求耗尽，再继续当前占位。 | 原子更新返回0后关闭源流，未调用文件输出流、未设置成功文件长度；count 不超额。 |
| TC05-07 / P0 / A05-3 | 已占位后、首字节前发生读错/客户端断开；另在传输中途失败。 | 已授予次数不退款，资源关闭；响应已提交时不追加 JSON 到文件内容中。 |
| TC05-08 / P0 / R05-3 | 数据库占位故障/超时；另模拟已提交响应丢失后客户端重试。 | 未确认授予不得输出；重试为新的资格申请，不能绕限额或盲目退原计数。 |
| TC05-09 / P1 / A05-4 | limit=null，多个正常 URL/流请求各授予一次。 | 无限额拒绝，每次授予仍原子加1，流完成不再后置重复加1。 |
| TC05-10 / P0 / A05-4 | 连续请求缩略图，随后请求原图预览流，另令缩略图不支持。 | 缩略图不计次、不返回原图；原流按一次资格计数；失败 fallback 不旁路计次。 |
| TC05-11 / P0 / R05-2 | 请求通过初次鉴权后暂停，分别禁用分享、关闭下载、推进时钟至过期，再继续占位。 | 最终条件 UPDATE 拒绝，不输出/不授予；口令修改在途语义按设计而非扩展为强制回收已授权流。 |
| TC05-12 / P1 / A05-4 | 有效大文件正常流式下载，开启既有限速并完整读取。 | 字节完整，限速机制仍调用，流/外部存储访问不包在数据库事务内；count 正好增加1。 |
| TC05-13 / P1 / R05-5、R05-6 | 授予一个预签名 URL，应用层重试申请；另在有效期内直接重复请求该 URL。 | 应用重试受剩余额度约束；已发 URL 可复用属于声明边界，不把对象存储 GET 次数当作应用授予计数或误报测试失败。 |
