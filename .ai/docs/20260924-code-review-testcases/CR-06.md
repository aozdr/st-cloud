# CR-06 搜索游标签名测试用例

来源：[需求](../20260924-code-review-design/CR-06/requirement.md)、[设计](../20260924-code-review-design/CR-06/design.md)。全部 NOT RUN。两个实例 I1/I2、同一合成测试共享密钥 K、相同用户/租户/空间/目录/查询与排序、稳定结果集（至少3页）；用可控时钟管理 TTL。K 由测试环境注入，不在文档填真实密钥。建议服务集成与双实例测试。

| ID / 优先级 / 映射 | 前置条件与步骤 | 预期结果与证据 |
|---|---|---|
| TC06-01 / P0 / A06-1 | I1 取第一页，I2 消费游标，第三页回 I1，均用 K。 | TTL 内验签成功，稳定数据集按既有分页无重复/遗漏；不是只验证单实例签名。 |
| TC06-02 / P0 / A06-4 | I1 生成游标后重启，用相同 K 在 TTL 内继续分页；再模拟滚动请求到 I2。 | 游标仍有效，普通发布不生成随机密钥导致失效。 |
| TC06-03 / P0 / A06-3 | 缺失配置、空串、纯空白分别启动包含搜索 Bean 的上下文。 | 初始化失败，错误明确指出配置名称；不生成随机 fallback，不到第一次分页才报错。 |
| TC06-04 / P1 / R06-2、R06-3 | 分别通过属性和环境变量注入 K；另启动不含搜索 Bean 的独立模块上下文。 | 支持既有两个配置入口；没有搜索 Bean 的模块不被无关密钥要求阻塞。 |
| TC06-05 / P0 / A06-2 | I1 使用 K 生成游标，I2 用不同密钥；另篡改单个 payload/signature 字节、截断或非法编码。 | 各变体按既有游标错误拒绝，不退回无游标查询或暴露内部密钥。 |
| TC06-06 / P0 / A06-2 | 保持游标不变，逐项更换 user、tenant、space、directory、query、既有绑定的排序/筛选条件。 | 所有被契约绑定的维度必须匹配；拒绝跨用户/租户复用，不泄漏原查询结果。 |
| TC06-07 / P0 / A06-2 | 使用未到期、到期边界、过期游标；其余输入一致。 | 按既有 TTL 边界接受/拒绝，跨实例不延长 TTL；错误可提示重新搜索。 |
| TC06-08 / P1 / R06-5 | 主动将所有实例密钥 K 切换为 K2，使用旧游标后重新搜索。 | 旧游标允许失效；新搜索可分页，无双密钥兼容承诺；普通发布则不得无意轮换。 |
| TC06-09 / P0 / R06-6 | 执行合法、非法游标、缺失密钥三类路径，观察响应与应用日志；检查测试配置与提交产物。 | 不出现真实秘密或完整敏感认证数据；测试值明确独立，源码不包含生产默认共享密钥。 |
