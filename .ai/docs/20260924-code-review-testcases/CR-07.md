# CR-07 缩略图资源保护与前端降级测试用例

来源：[需求](../20260924-code-review-design/CR-07/requirement.md)、[设计](../20260924-code-review-design/CR-07/design.md)、[UI 规格](../20260924-code-review-design/CR-07/uispec.md)。全部 NOT RUN。

参数 B=`max-thumbnail-source-bytes`、P=`max-thumbnail-pixels`、C=`max-thumbnail-concurrent-generations`，默认分别为20971520、16000000、2。用受控源流、图片头、ImageReader 调用探针及信号量屏障检查“解码前”而非只观察最终错误。资源压测应在隔离环境以明确内存预算进行，不在本轮运行。普通预览、历史版本和匿名分享三入口须执行同一组资源用例；UI 另以网络请求记录断言 fallback。

| ID / 优先级 / 映射 | 前置条件与步骤 | 预期结果与证据 |
|---|---|---|
| TC07-01 / P1 / A07-1 | 参数化 jpg/jpeg/png/gif/bmp，分别请求 sm/md/lg；源有效且低于阈值。 | 输出为可解码 JPEG，不仅后缀为jpg；边长≤150/400/1200、宽高≥1；GIF 只取首帧，主图动画能力不被全局禁用。 |
| TC07-02 / P0 / A07-2 | WebP/SVG 分别访问缩略图生成和普通主图预览。 | 缩略图不进入 ImageIO 全图解码；主图使用已授权原文件路径，浏览器不支持则明确降级；不伪造 JPEG。 |
| TC07-03 / P0 / A07-3 | 有效图片源大小分别 B-1、B、B+1；HEAD 对应真实大小。 | B+1 在完整读入/解码前拒绝；不超过 B 且其他条件合法可生成；无超限缓存对象。 |
| TC07-04 / P0 / A07-3 | HEAD 小于 B/缺失长度信息，实际流超过 B；另模拟读取途中对象增长。 | 实际流硬上限仍生效，不 readAllBytes；最多有限缓冲超读并停止、不完整解码/PUT；元数据异常不能无限读。 |
| TC07-05 / P0 / A07-3 | 图片头宽高乘积分别 P-1、P、P+1（可用可控 reader）；另为巨大维度和非法非正宽高。 | 超限/非法在 reader.read 前拒绝；乘积计算不溢出而误放行；边界合法且源数据完整才允许解码。 |
| TC07-06 / P0 / A07-4 | .jpg 名称包含非白名单内容、无 reader 文件、损坏头和截断内容，分别调用。 | 按实际 reader/格式拒绝或报受控错误；不依赖后缀放行，所有资源释放，无空 JPEG 写入。 |
| TC07-07 / P0 / A07-4 | C 个请求拿到生成许可并暂停，在同一实例发第 C+1 个请求。 | 同时解码数≤C；超容量快速降级而非无界排队/读大源；完成一个后新请求可成功。保存最大并发与读取计数。 |
| TC07-08 / P0 / A07-4 | 分别在源读取、尺寸解析、解码、JPEG 编码、存储写入阶段注入异常，再发正常请求。 | 源/图像流、reader、Graphics、临时文件、许可均释放；编码失败不 PUT 无效对象；正常请求不被泄漏许可永久阻塞。 |
| TC07-09 / P1 / A07-4 | B/P/C 分别设0或负值启动；再注入合法自定义低阈值启动。 | 非法配置初始化失败；合法配置按实际注入值执行，不能固定使用默认值。 |
| TC07-10 / P0 / A07-3 | 当前版本小、历史版本超限；另反向设置，并为两版本准备不同内容。 | 历史缩略图按历史对象 HEAD/内容判断，不用当前 fileSize；成功输出对应历史版本，失败不回退当前内容。 |
| TC07-11 / P0 / A07-5 | 无查看权限用户访问普通/历史缩略图；分享错误提取码、关闭下载、子树外节点访问分享缩略图。 | 鉴权先于生成，拒绝时不开放原对象 URL/字节；失败 fallback 不绕过权限或范围。 |
| TC07-12 / P0 / A07-5 | 分享分别请求支持、不支持、超限、损坏缩略图，再点击主图。 | 所有缩略图请求 count 不变且不返回原图；主图流按 CR-05 授予计数，失败不借缩略图路径绕限额。 |
| TC07-13 / P1 / R07-4 | 胶卷含多张大图/WebP/SVG；模拟缩略图404/业务错误/加载失败并切换选择。 | 显示通用图标，文件名/选择/前后导航可用；不自动批量请求大原图，不因 onError 无限循环请求。 |
| TC07-14 / P0 / R07-2 | 主图展示含脚本/外链的合成 SVG；观察 DOM 插入方式和权限 URL 来源。 | 仅 img 消费，不 innerHTML/object/iframe 执行文档；无未经鉴权公开 URL；浏览器限制下的失败显示可理解提示。 |
| TC07-15 / P1 / A07-4 | 已有有效缓存缩略图；另让缓存 HEAD 返回404、403、超时三种情况。 | 缓存命中不占解码许可；仅确认不存在时生成；其他存储错误不伪造缓存成功，不无条件回退大原图。 |
| TC07-16 / P0 / R07-5、R07-7 | 普通/历史/分享同时触发同实例生成，另跨两实例请求同缓存键。 | 三入口共用该实例资源上限，无未保护路径；跨实例允许有限重复生成但最终对象完整，不能据此宣称全局并发上限。记录每实例峰值。 |
