# 数据库差异、字符串 ID 与发布兼容测试用例

来源：仓库数据库版本规则，CR-01/02/04 需求设计，迁移 `44_team_role_bigint.sql`、`45_user_security_version.sql`，用户“前端用的 id 是字符串”约束，以及第一轮 Review 的 JWT ID 问题。全部 NOT RUN。

以下步骤描述未来在隔离开发/测试数据库的执行方式，不构成本轮迁移/连接授权。历史记录的本机迁移 `20260924.1` 和既有对比结果不能复制为本册 PASS。迁移重放使用可销毁夹具库，不对已迁移的真实开发库重复执行 ADD COLUMN。应保留迁移前后数据快照与对比输出；生产不在范围内。
