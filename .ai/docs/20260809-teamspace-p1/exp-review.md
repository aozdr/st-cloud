# UI/UX 设计文档：团队空间 P1 协作增强

> 归属 exitCriteria: EXP_DESIGN（依赖 REQ_ANALYSIS）
> 关联需求文档: `.ai/docs/20260809-teamspace-p1/requirement.md`
> 设计系统遵循现有 Tailwind 设计令牌

## 1. 设计概述

P1 在 P0 基础上新增 4 项协作增强功能，设计原则：
- **通知全局化**：通知铃铛挂载到全局 TopBar，非空间内组件
- **评论侧边化**：评论作为文件侧边栏面板，不遮挡文件列表
- **权限上下文化**：文件夹权限设置入口在文件右键菜单/操作栏
- **搜索轻量化**：空间搜索/排序/置顶在现有列表页头部扩展

## 2. 页面改动清单

| 页面/组件 | 改动类型 | 说明 |
|-----------|----------|------|
| TopBar | 扩展 | 新增通知铃铛 |
| NotificationBell | 新增 | 通知铃铛 + 下拉列表 |
| CommentPanel | 新增 | 文件评论侧边栏 |
| FolderPermissionDialog | 新增 | 文件夹权限设置弹窗 |
| TeamPage | 扩展 | 搜索框 + 排序 + 置顶 |
| TeamSpacePage | 扩展 | 评论入口 + 文件夹权限入口 + 权限控制按钮 |

## 3. 详细设计

### 3.1 P1-3 通知铃铛（NotificationBell）

**位置**：TopBar 右侧，用户头像左边。

```
[搜索栏 ........] [🔔③] [👤头像]
                 │
                 ▼
┌─ 通知 ──────────────────────────┐
│                          全部已读 │
├──────────────────────────────────┤
│ 💬 张三 在「设计稿.fig」中@了你   │
│    2分钟前                       │
├──────────────────────────────────┤
│ 👥 李四 邀请你加入「产品组」      │
│    15分钟前                      │
├──────────────────────────────────┤
│ ⚠️ 你被移出「测试空间」           │
│    1小时前                       │
├──────────────────────────────────┤
│              查看全部通知 →       │
└──────────────────────────────────┘
```

- 铃铛图标 + 未读数红色圆点（数字 >99 显示 99+）
- 每 30s 轮询未读数
- 点击铃铛展开下拉（最近 20 条），已读通知灰色
- 点击单条通知：标记已读 + 跳转关联页面
- "全部已读"一键标记
- "查看全部通知"跳转通知列表页（分页）
- 通知图标映射：MENTION💬 / TEAM_INVITE👥 / MEMBER_CHANGE⚠️ / FILE_CHANGE📁

### 3.2 P1-2 文件评论侧边栏（CommentPanel）

**入口**：文件列表中文件行的操作菜单新增"评论"按钮（带评论数角标）。

```
┌─ 文件列表 ──────────────┐  ┌─ 评论 ──────────────┐
│                         │  │  设计稿_v2.fig       │
│  📄 设计稿_v2.fig       │  │  3 条评论            │
│     [评论③] [更多]      │  ├──────────────────────┤
│                         │  │ [头像] 张三          │
│  📄 需求文档.docx       │  │ 这个设计稿很棒！     │
│     [评论] [更多]       │  │ 2分钟前 [回复]       │
│                         │  │   ├ [头像] 李四      │
│                         │  │   │ 同感！           │
│                         │  │   └ 1分钟前 [回复]  │
│                         │  ├──────────────────────┤
│                         │  │ [输入评论... @提及]  │
│                         │  │              [发送]  │
└─────────────────────────┘  └──────────────────────┘
```

- 评论侧边栏从右侧滑出，宽度 320px
- 评论文本框支持输入 `@` 触发成员选择浮层
- @提及选择成员后插入 `@昵称` 标记，实际传 userId 列表
- 评论列表按时间正序，分页加载（滚到底部加载更多）
- 二级回复缩进显示
- 每条评论可编辑（本人）、删除（本人/管理员）
- 发送评论时如有 @提及，触发通知

### 3.3 P1-1 文件夹权限设置（FolderPermissionDialog）

**入口**：文件夹右键菜单/操作栏新增"权限设置"按钮（仅管理员可见）。

```
┌─ 文件夹权限：财务文件夹 ────────────────┐
│                                          │
│  继承状态：继承自父文件夹 [中断继承]     │
│                                          │
│  权限规则：                              │
│  ┌────────────────────────────────────┐ │
│  │ 👤 张三 (@zhangsan)    [查看 ▼] [×]│ │
│  ├────────────────────────────────────┤ │
│  │ 👥 角色：查看者       [无权限 ▼] [×]│ │
│  ├────────────────────────────────────┤ │
│  │ 👤 李四 (@lisi)        [编辑 ▼]  [×]│ │
│  └────────────────────────────────────┘ │
│                                          │
│  添加规则：                              │
│  [搜索用户... ▼]  [角色▼]  [权限▼] [添加]│
│                                          │
│  权限说明：                              │
│  · 查看：可浏览文件                      │
│  · 编辑：可上传/修改/删除                │
│  · 管理：可管理权限                      │
│  · 无权限：不可见                        │
│                                          │
│                    [取消]  [保存]        │
└──────────────────────────────────────────┘
```

- 继承状态显示当前是否继承父文件夹权限
- "中断继承"后当前文件夹独立设置权限
- 权限规则列表：每条显示授权对象 + 权限级别 + 删除
- 添加规则：搜索用户或选择角色 + 选权限级别 + 添加
- 权限级别下拉：查看/编辑/管理/无权限
- 文件浏览器中"无权限"文件夹不展示

### 3.4 P1-4 空间搜索与排序

**位置**：TeamPage 空间列表头部扩展。

```
┌──────────────────────────────────────────────┐
│ [📁] 团队空间              [+ 创建空间]      │
│ [🔍 搜索空间名称...]  [排序▼]               │
├──────────────────────────────────────────────┤
│  📌 产品研发组    [📌]                       │  ← 置顶空间
│     8成员 · 2.3GB/10GB                       │
├──────────────────────────────────────────────┤
│  📁 设计组        [📌]                       │
│     5成员 · 1.1GB/5GB                        │
├──────────────────────────────────────────────┤
│  📁 测试空间      [📌]                       │
│     3成员 · 0.5GB/2GB                        │
└──────────────────────────────────────────────┘
```

- 搜索框：实时按名称模糊搜索
- 排序下拉：创建时间（默认）/ 成员数 / 存储用量，点击切换升降序
- 每个空间卡片右上角图钉图标，点击切换置顶
- 置顶空间（is_pinned=1）显示在最前，带 📌 标记
- 置顶空间之间按排序规则排列

### 3.5 权限控制按钮显隐（TeamSpacePage）

文件浏览器中根据文件夹权限控制操作按钮：
- 查看权限（2）：仅显示浏览、下载
- 编辑权限（1）：显示上传、创建文件夹、重命名、移动、删除
- 管理权限（0）：显示权限设置入口
- 无权限（-1）：文件夹不展示

## 4. 交互细节

- 通知铃铛下拉和评论侧边栏均用 `fixed`/`absolute` 定位，不挤压主内容
- 评论 @提及浮层复用 P0 用户搜索下拉的交互模式
- 文件夹权限设置弹窗 `max-w-lg`
- 空间搜索防抖 300ms
- 所有新增弹窗沿用现有 `bg-black/50` 遮罩 + 居中卡片模式

## 5. 无障碍

- 铃铛按钮 `aria-label="通知"` + `aria-badge` 未读数
- 评论输入框 `aria-label="评论内容"`
- @提及选择浮层 `role="listbox"`
- 权限级别选择 `aria-label="权限级别"`
- 图钉按钮 `aria-label="置顶/取消置顶"`

## 6. 响应式

- 通知下拉移动端撑满宽度
- 评论侧边栏移动端从底部滑出（全宽半高）
- 文件夹权限弹窗移动端撑满
- 空间搜索框移动端独占一行
