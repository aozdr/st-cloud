# 测试用例：文件跨空间操作与元数据增强

> 迭代：20260829-file-ops
> 依赖：design.md（已确认）

## 1. 转存 / 保存到我的网盘

| 编号 | 前置 | 操作 | 预期 |
|------|------|------|------|
| TS-01 | 私密分享，提取码正确 | 转存到个人空间当前目录 | 转存成功，目标产生节点，ref_count+1，返回新增节点 |
| TS-02 | 私密分享，提取码错误 | 转存 | 拒绝，返回提取码错误 |
| TS-03 | 分享已过期 / 已取消 | 转存 | 拒绝，提示分享不可用 |
| TS-04 | 分享权限点不含 view | 转存 | 拒绝，提示无读取权限 |
| TS-05 | 目标团队空间 | 转存到团队目录 | 需当前用户对目标目录有写权限，否则拒绝 |
| TS-06 | 目标目录已有同名 | 转存 | 自动加 `_1` 序号，不覆盖 |
| TS-07 | 分享为文件夹 | 转存 | 递归复制整棵子树，保持结构 |
| TS-08 | 目标空间配额不足 | 转存 | 拒绝，提示剩余空间不足 |

## 2. 元数据编辑

| 编号 | 前置 | 操作 | 预期 |
|------|------|------|------|
| TM-01 | 个人文件 | 设置 title/description/cover/tags | 保存成功，重新读取返回新值 |
| TM-02 | 团队文件 | 设置元数据 | 需对应权限，view 可读、upload/manage 可写 |
| TM-03 | 同节点重复挂同标签 | 重复请求 | 幂等，不产生重复关联 |
| TM-04 | 删除文件到回收站 | 读取元数据 | 元数据随节点隐藏 |
| TM-05 | 从回收站恢复 | 读取元数据 | 元数据重新可见 |
| TM-06 | 永久删除 | 元数据 | 关联记录删除 |
| TM-07 | 无元数据旧节点 | 读取 | 返回空元数据，前端隐藏编辑入口 |

## 3. 跨空间移动 / 复制

| 编号 | 前置 | 操作 | 预期 |
|------|------|------|------|
| TC-01 | 个人文件 | 复制到团队空间 | 目标产生副本，源不变，目标配额 +size，ref_count+1 |
| TC-02 | 团队文件 | 复制到个人空间 | 目标产生副本，源不变，个人配额 +size |
| TC-03 | 个人文件 | 移动到团队空间 | 目标新增，源移除；源配额 -size，目标 +size（净 0） |
| TC-04 | 团队文件 | 移动到个人空间 | 目标新增，源移除；空间归属与 owner 重设 |
| TC-05 | 团队A→团队B | 移动/复制 | 源/目标 spaceId 区分正确，B 空间配额调整 |
| TC-06 | 目标目录无写权限 | 移动/复制 | 拒绝 |
| TC-07 | 目标=源自身/子目录 | 移动/复制 | 拒绝 |
| TC-08 | 目标空间配额不足 | 移动 | 整体回滚，不产生半成品 |
| TC-09 | 正在编辑的文件 | 移动 | 拒绝（沿用 assertNotEditing） |
| TC-10 | 目标目录同名 | 移动/复制 | 自动加序号 |
| TC-11 | 文件夹递归 | 移动/复制 | 子树全部迁移，path 前缀正确更新 |

## 4. 排序增强

| 编号 | 前置 | 操作 | 预期 |
|------|------|------|------|
| TJ-01 | 表格视图 | 点击类型列头 | 按后缀/类型排序，升/降可切换 |
| TJ-02 | 任意视图 | 文件夹优先开关 | 文件夹始终置顶（既有能力保留） |
| TJ-03 | 手动拖拽 | 调整顺序 | 顺序保存到 localStorage，刷新后保留 |
| TJ-04 | 切换设备 | 手动排序 | 不保留（本地持久化，符合本期范围） |

## 5. 回归

- 既有个人空间 `move/copy`、团队空间 `moveTeamFiles/copyTeamFiles` 行为不变。
- 分享访问/下载/预览接口不受影响。
- 文件列表/详情/收藏/同步事件（FILE_INDEX / SYNC_CHANGE）路径不回退。
