# 定版用例

1. 两个不同 owner 的团队父子：管理员删除根，只根进入回收列表；恢复后同一空间和父子 ID/路径不变，子文件可访问。
2. 空间拥有者与管理员均可列出/恢复其他上传者节点；普通成员即使是节点 owner 也不可列出、恢复、永久删除；无成员、已删除成员、过期成员、外部协作关闭、禁用空间与跨租户拒绝。
3. 恢复时父目录已回收/祖先不可访问，回到相同团队根；同空间其他 owner 同名导致重命名，并更新不同 owner 子孙路径；其他空间/个人同名不影响。
4. 永久删除混合 owner 子树，正常状态及跨空间/租户节点不受影响，按团队容量退还且个人容量不变；重复 ID 不重复扣减。
5. 清空只清个人自己的回收项及可管理空间，普通成员不能清团队回收项；独立回收子孙只被最外层根递归清理。
6. 现有个人回收、恢复、物理删除、权限集成测试和 SchemaConsistencyTest 通过；H2/MySQL 列比对通过，生产结构不变。
7. 真实 Docker 依赖健康，完整后端成功启动；独立数据真实 HTTP 团队创建文件夹→删除→回收列表→恢复→团队列表可见；普通成员 HTTP 不可操作，个人路径正常。
