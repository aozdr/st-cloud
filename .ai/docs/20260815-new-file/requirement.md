# 一、需求概述

## 1.1 功能名称

新建文件（空白文档/表格/演示/文本）

## 1.2 背景说明

- 当前仅支持「新建文件夹」，不支持新建空白文件（主流网盘标配能力）
- 已集成 OnlyOffice 在线编辑，新建 Office 文件后可立即进入编辑，形成完整闭环

## 1.3 用户角色

| 用户角色 | 权限 | 使用场景 |
|---------|------|---------|
| 个人用户 | 本人目录可新建 | 在个人空间新建文档/表格/文本 |
| 团队用户 | 有 upload 权限的目录 | 在团队空间新建文件 |

# 二、业务需求分析

## 2.1 用户故事

- 作为个人用户，我希望在网盘里直接新建 Word/Excel/PPT/文本，从而不用本地创建再上传
- 作为团队编辑者，我希望在团队目录新建文档并在线编辑，从而直接开始协作

## 2.2 功能列表

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|--------|
| F1 | 新建文本 | 新建空白 .txt（默认名「新建文本文档.txt」） | P0 |
| F2 | 新建 Word | 新建空白 .docx（OnlyOffice 可编辑） | P0 |
| F3 | 新建 Excel | 新建空白 .xlsx（OnlyOffice 可编辑） | P0 |
| F4 | 新建 PPT | 新建空白 .pptx（OnlyOffice 可编辑） | P1 |
| F5 | 重名处理 | 同目录重名自动追加 (1)(2) 序号 | P0 |

## 2.3 业务流程

```
文件列表 → 「新建」菜单 → 选择类型
   ↓
前端调 POST /api/file/new?type=txt|docx|xlsx|pptx&parentId=...
   ↓
后端生成空白模板内容 → 落 S3 → 创建 file_node（已完成状态）
   ↓
返回新节点 → 列表刷新显示
   ↓
docx/xlsx/pptx：自动打开 OnlyOffice 编辑器（可选）
```

# 三、功能边界

## 包含范围

- 新建 txt/docx/xlsx/pptx 空白文件；默认命名 + 重名自动序号
- 新建的 Office 文件可走既有能力：预览/下载/分享/在线编辑/版本/同步
- 入口：文件列表工具栏「新建」下拉菜单 + 空白区域右键菜单

## 不包含范围

- 不做富文本编辑器自研（沿用 OnlyOffice）
- 不做模板库/预设样式（仅空白文档）
- 不改变现有上传/同步/权限模型

# 四、业务规则

- 权限：个人目录本人可新建；团队目录需 upload 权限（复用现有权限判定）
- 新建即完成：file_node 状态为正常、uploadStatus=已完成，不经过分片上传
- 配额：空白文件按实际字节计入配额（txt 空文件约 0 字节；docx/xlsx/pptx 模板约几 KB）
- 重名：同目录同名自动追加 `(1)` `(2)` 序号（复用现有 resolveNameConflict）
- 新建不触发同步变更日志？——新建是文件变更，应触发 SyncChangeEvent(CREATE) 让桌面端同步（见 P2）

# 五、异常场景

| 场景 | 处理方式 |
|------|---------|
| 无权限目录 | 隐藏「新建」入口或提示无权限 |
| 配额不足 | 返回 STORAGE_QUOTA_EXCEEDED |
| 模板生成失败 | 返回错误，不创建半成品节点 |

# 六、非功能需求

- 新建接口响应 < 500ms（模板为内置静态资源，无网络依赖）
- 模板兼容 OnlyOffice 9.x（标准 OOXML 格式）

# 七、验收标准

- Given 我在有权限目录，When 选择「新建 Word」，Then 出现「新建文档.docx」且可打开编辑
- Given 同目录已有「新建文档.docx」，When 再次新建，Then 生成「新建文档 (1).docx」
- Given 团队查看者（无 upload），When 打开新建菜单，Then 无新建入口或提示无权限
- Given 新建 txt，When 完成，Then 文件可预览/下载，内容为空文本
- Given 配额不足，When 新建，Then 返回存储空间不足且不产生半成品

# 八、遗留问题点（Grill Me 拷打收敛）

| 编号 | 遗留问题 | 影响 | 建议方案 | 用户裁决 |
|------|---------|------|---------|---------|
| P1 | 新建 Office 文件的空白模板来源：服务端内置模板 vs 前端生成 | 模板兼容性与实现成本 | 服务端内置 3 个标准 OOXML 空白模板（docx/xlsx/pptx，各约 3-5KB），保证 OnlyOffice 可打开 | ✅ 按建议（20260815 用户确认） |
| P2 | 新建文件是否触发同步（桌面端） | 桌面端同步目录会出现新建文件 | 触发 SyncChangeEvent(CREATE)，桌面端自动同步到本地 | ✅ 按建议（20260815 用户确认） |
| P3 | 新建 Office 文件后是否自动打开编辑器 | 交互效率 vs 打扰 | 新建 docx/xlsx/pptx 后自动进入 OnlyOffice 编辑；txt 仅留在列表 | ✅ 按建议（20260815 用户确认） |

> 问题点 > 3 时不得定版，继续拷打收敛后再产出。

# 九、风险分析

| 风险 | 影响 | 解决方案 |
|------|------|---------|
| 模板与 OnlyOffice 版本不兼容 | 新建文件打不开 | 模板用标准 OOXML，实测验证 |
| 新建绕过上传校验 | 配额/权限绕过 | 复用既有配额与权限判定 |
