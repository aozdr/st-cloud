# Security Review：新建文件

> 归属：SECURITY_REVIEW（条件项：涉及文件创建与权限，启用；主线程自查记录）

## 结论

**PASS**，无高危问题。

## 审查项

### 1. 越权新建

- 个人端点：父目录非本人（非租户管理员）→ FORBIDDEN ✅
- 团队端点：TeamController 复用 upload 权限点 + checkNotLocked；服务内校验父目录属于该空间 ✅

### 2. 类型注入

- type 白名单仅 txt/docx/xlsx/pptx，非法类型返回 400，防任意后缀/路径注入 ✅

### 3. 配额绕过

- 配额预检 + 事务内原子扣减（条件 UPDATE，0 行抛异常回滚），不产生半成品节点 ✅
- 云盘总容量校验 ✅

### 4. 数据一致性

- 模板落 S3 复用 FileObject 去重（同 md5 共享对象）；file_node 创建即完成状态 ✅
- 事件发布与文件创建同事务（Outbox），回滚即无事件 ✅

## 风险

- 模板内容为服务端静态资源，无用户输入，注入面低。

## 结论

安全设计成立，可进入测试执行。
