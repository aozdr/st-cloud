# 需求发现报告：百度网盘 vs 星云盘 功能差距分析

## 1. 调研背景与范围

**调研动机**：用户反馈收藏功能完善后发现星云盘相比成熟网盘产品在功能广度和体验细节上仍有差距，要求系统性对比百度网盘，识别缺失功能与 UI/UX 改进点。

**调研对象**：百度网盘 Web 端 + PC 桌面端（2024-2025 版本）

**本产品现状**：星云盘已实现文件管理、分片上传/秒传、版本管理、回收站、分享、团队空间、文件同步、全文搜索、文件预览、传输限速、审计日志、RBAC、多租户、收藏、分类浏览。

**调研维度**：核心功能缺失、文件预览体验、传输管理、UI/UX 细节、移动端

## 3. 功能差距清单

按价值与实现成本分类：

### 🔴 高价值 / 中等成本（建议优先立项）

| # | 功能 | 价值 | 成本 | 说明 |
|---|------|------|------|------|
| G1 | **在线解压** | 高 | 中 | 用户上传压缩包后可直接在网盘内浏览/提取，免去下载-解压-重传。后端需集成压缩库（Apache Commons Compress / zip4j），前端弹窗展示压缩包内容树 |
| G2 | **视频倍速 + 字幕** | 高 | 低 | Plyr 播放器原生支持倍速（0.5x-2x），只需暴露设置面板；字幕加载支持 .srt/.vtt 同名文件或内嵌字幕 |
| G3 | **图片相册模式** | 高 | 低 | 图片预览增加左右切换、缩放、旋转。当前 PreviewModal 已有图片预览基础，需增强为相册浏览模式 |
| G4 | **二维码分享** | 中 | 低 | 分享对话框增加二维码生成（qrcode 库），方便移动端扫码访问 |
| G5 | **存储空间分析** | 中 | 低 | 首页或设置页增加按文件类型的存储占用饼图/柱状图（后端已有文件数据，前端用 Recharts 渲染） |
| G6 | **传输单任务暂停/继续** | 高 | 中 | 当前传输仅支持队列级操作，增加单任务暂停/继续提升大文件传输体验 |
| G7 | **批量重命名** | 中 | 低 | 选中多个文件后支持批量重命名（前缀+序号、替换、正则），纯前端逻辑 |
| G8 | **空状态引导插图** | 中 | 低 | 回收站空、收藏空、搜索无结果等场景增加 SVG 插图 + 操作引导，提升首次使用体验 |

### 🟡 中价值 / 中高成本（建议规划评估）

| # | 功能 | 价值 | 成本 | 说明 |
|---|------|------|------|------|
| G9 | **离线下载** | 高 | 高 | 支持磁力链接/HTTP/FTP 离线下载到网盘。后端需集成下载引擎（aria2），新增任务管理模块。百度网盘核心差异化功能 |
| G10 | **文档在线编辑** | 高 | 高 | 集成 OnlyOffice/Collabora 实现在线文档编辑。需部署文档编辑服务，改造预览流程 |
| G11 | **文件加密隐藏** | 中 | 中 | 文件夹级别加密，需密码访问。后端加密存储元数据，前端增加加密入口 |
| G12 | **重复文件检测** | 中 | 中 | 扫描用户空间内重复文件（基于 MD5），提示用户清理。后端聚合查询 + 前端报告 |
| G13 | **传输浮窗** | 中 | 中 | 全局悬浮传输进度条，任意页面可见传输状态。需提取传输状态为全局 Provider |
| G14 | **图片瀑布流** | 中 | 中 | 图片分类页增加瀑布流视图，用 CSS columns 或 Masonry 布局 |
| G15 | **传输速度图表** | 低 | 中 | 传输管理页增加实时速度折线图 |
| G16 | **传输历史记录** | 低 | 中 | 记录已完成的上传/下载历史，本地 SQLite 存储 |

### 🟢 低价值或与定位不符（建议暂缓）

| # | 功能 | 说明 |
|---|------|------|
| G17 | PDF 批注 | 百度网盘的 PDF 批注功能较基础，专业用户更倾向专业工具；自建网盘用户群体对此需求低 |
| G18 | OCR 文档扫描 | 需集成 OCR 引擎（Tesseract），成本高且使用频率低 |
| G19 | 笔记本/备忘录 | 偏离网盘核心定位，与文件管理关系不大 |
| G20 | 内容社区/资讯 | 百度网盘的内容运营功能，自建网盘无需 |
| G21 | 分享到社交平台 | 国内社交平台 API 需备案/审核，自建部署场景价值低 |
| G22 | 移动端 | 需额外开发 React Native / Flutter，周期长；桌面端+Web 已覆盖核心场景 |

## 6. 总结

星云盘在**文件管理核心能力**（上传/下载/秒传/版本/回收站/分享/团队/同步/搜索）上已覆盖百度网盘的主要功能，但在以下三个维度存在明显差距：

1. **文件消费体验**：视频倍速/字幕、图片相册模式、在线解压——这些是用户日常高频使用的"看/听/用"场景
2. **传输管理精细化**：单任务暂停/继续、传输浮窗、速度图表——大文件场景下的体验差距
3. **UI/UX 细节打磨**：空状态引导、拖拽排序、存储分析——影响首次使用感受和日常操作效率

建议优先推进第一梯队（6 项低成本高收益功能），再逐步规划第二梯队的核心差异化功能。第三梯队的离线下载和在线编辑虽价值高，但实现成本和运维复杂度也高，建议根据用户反馈再决定是否投入。
