# 团队搜索与文件关注交互说明

- 版本：tsw-design-r2；作者：GPT-6；沿用现有界面组件、颜色、字号和权限模型。

## 1. 搜索入口和结果

团队空间文件 Tab 工具区增加“搜索团队文件”。进入 `/search?scope=team&spaceId=<id>`；若从子目录进入，带 folderId，并显示“当前文件夹及子文件夹”，允许切换“整个空间”。全局 SearchPage 保留个人模式，增加团队模式及已加入空间选择；切换空间清空目录范围、结果、游标。

复用现有搜索输入及类型/大小/时间筛选。团队范围不可由输入的任意空间名称扩大；服务端空间校验失败时清空旧结果并显示“无权访问该空间或空间已不存在”。

结果展示文件图标、当前名称、团队/目录位置、正文摘要、大小和更新时间。显示“已加载 N 项”，有下一页时显示“加载更多”；不显示 ES 总数。点击文件夹进入 `/team/<spaceId>?folderId=<id>`；点击文件进入对应团队目录并定位目标，按已有团队预览/编辑入口打开，不能用个人 FileNode 预览的默认权限上下文。

加载时保留当前合法条件但不混入上一个空间结果；快速切换查询条件用请求序号或 AbortController 防止迟到响应覆盖。追加加载防重复点击和 fileId 重复。

## 2. 关注操作

个人/团队文件详情面板提供“关注变更 / 已关注”按钮；文件夹同样支持。按钮文案或辅助说明：文件夹“提醒此文件夹及子文件夹内的变更”；文件“他人修改时通知我”。关注状态从服务端取得，提交中禁用，失败还原并提示原因。此入口可在移动端通过详情面板到达，不依赖右键。

侧边导航加入“我的关注”（铃铛或现有图标体系中的相近图标），路由 `/following`。列表列出名称、个人/团队归属、路径、关注时间、取消关注操作。服务端失效项只显示“内容已不可用”和取消按钮，不渲染缓存旧名称。列表有加载、空、错误和下一页状态。

首次关注后的反馈：“已关注，后续变更将在站内通知中提醒”。取消无需额外弹窗；操作可重新关注，但不会补发旧事件。

## 3. 通知

沿用 NotificationBell。FILE_CHANGE 显示文件变更图标；可访问通知打开服务端核权返回的个人/团队目标，标记已读失败不能伪装成功。删除/失权通知显示通用不可用文案，不能跳转到失权空间或文件。点击旧的 team/comment 通知维持现有行为。

通知条目使用 button 或有等价键盘语义的控件，支持 Enter/Space；弹层支持 Escape 关闭、关闭后焦点回到铃铛。窄屏宽度不超过视口（保留左右间距）。

## 4. 状态文案

| 状态 | 反馈 |
|---|---|
| 未输入搜索词 | 输入关键词，搜索团队文件名和文档内容 |
| 零结果 | 未找到相关文件，可调整关键词或范围；新文件索引可能尚未完成 |
| ES 故障 | 搜索暂时不可用，请稍后重试；不展示成零结果 |
| 扫描预算达到上限 | 搜索范围较大，请选择文件夹或增加筛选条件 |
| 游标过期 | 搜索已过期，请重新搜索（操作按钮重置游标） |
| 空关注列表 | 还没有关注内容，可从文件详情关注变更 |
| 关注请求失败 | 保留原状态，展示服务端可理解的失败原因 |
| 通知目标失效 | 关注内容已不可用 |
