# 安全审查记录：同步引擎 V2 重构

> 归属 SECURITY_REVIEW（条件项，本次涉及文件删除/S3/管理员接口，启用）。

# 一、审查范围

- 管理员清理接口 `POST /api/admin/sync/cleanup-junk`
- 云端删除保护（DELETE delta 处理）
- S3 物理对象删除（引用计数）
- 客户端本地文件清理（机器格式匹配）

# 二、审查结论

| 检查项 | 结论 | 说明 |
|--------|------|------|
| 接口鉴权 | 通过 | @PreAuthorize("hasRole('ADMIN')")，与 st-admin 一致 |
| 越权访问 | 通过 | permanentDeleteAdmin 不依赖用户上下文，仅管理员可达 |
| 误删风险 | 通过 | 名称正则严格匹配机器格式；dry-run 先行 |
| S3 删除安全 | 通过 | file_object.ref_count 归零才物理删除，仍被引用对象不删 |
| 本地修改保护 | 通过 | 云端 DELETE 需 mtime+md5 双条件；全量对账同名不同内容走冲突流程 |
| SQL 安全 | 通过 | 使用 MyBatis-Plus 参数化查询，无字符串拼接注入 |
| 敏感数据 | 通过 | 不涉及凭据/隐私数据输出 |

# 三、残留风险

- 普通用户文件恰好匹配机器格式（`xxx (本地-20260815141555).zip`）存在理论误删风险 → 已通过 dry-run + 正则收窄 + 引用计数删除缓解
- 管理员 Token 泄露即可触发清理 → 建议清理在维护窗口执行

# 四、结论

```
安全审查通过
```
