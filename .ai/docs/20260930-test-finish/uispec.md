# 成员角色错误恢复
目标用户：团队空间管理员；场景：为已有成员修改角色时服务端拒绝或网络失败。
范围：既有成员管理弹窗内的角色选择，继承当前视觉规范，禁止重设计页面。
正常：徽标表示已保存角色；选择后提交完整字符串roleId，提交中禁用选择。成功后更新徽标与选择，消除错误。
失败：徽标保留旧角色，下拉保留本次选择；相邻显示“未保存”和带成员名称的可访问重试按钮，toast显示原因；不得虚假成功。重试提交同一字符串ID；成功恢复正常。
并发/边界：每成员独立状态，失败不修改其他成员；未知角色保持失效提示；同名角色按ID区分。关闭重开仍保留本页面的待提交选择，不写localStorage。
键盘/辅助技术：原生select/button，aria-invalid及aria-describedby关联错误，role=status宣布状态，不移除原有焦点样式。
验收：浏览器对权限失败、断网、恢复重试分别断言选择/已保存数据；相邻大ID和同名ACL提交回显精确。API/数据模型不变；无待决事项。
