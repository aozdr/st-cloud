> 状态：**初稿**，方向决策基于 HTML 实证，已推翻既有 `pikpak-redesign-requirement.md` 的"深色优先紫蓝"方向

---

## 1. 背景

### 1.1 需求来源
用户要求参考 PikPak 网盘（mypikpak.com）重做星云盘前端 UI/UX。需求发现 Agent 基于 `docs/PikPak.html` 实际 DOM/CSS 提取了 27 条 UI/UX 差距（D1-D27），发现既有需求文档方向（深色优先紫蓝）与 PikPak 实证（浅色优先蓝色 #306eff）冲突。

### 1.2 问题
当前星云盘前端文件网格为扁平图标 + 1:1 正方形缩略图，侧边栏深色，视觉偏"文件管理工具"。PikPak 的核心体验差异在于：文件夹 3D 立体封面、视频缩略图+播放按钮、强制 16:9 宽高比、模糊背景填充、浅色侧边栏+淡蓝选中态、分层圆角体系。

### 1.3 目标
全站视觉从"文件管理工具"向"媒体云盘"靠拢，保留全部文件管理功能完整性。分两阶段交付，阶段1 纯前端视觉系统，阶段2 含后端支持的媒体化文件呈现。

## 3. 用户故事

### 3.1 阶段1（纯前端视觉系统）

- **作为**网盘用户，**我希望**打开文件页时看到浅色清爽的界面和统一的 16:9 缩略图，**以便**快速浏览文件内容而非只看图标
- **作为**网盘用户，**我希望**侧边栏导航选中项有淡蓝底色提示，**以便**一眼知道当前所在位置
- **作为**网盘用户，**我希望**文件缩略图无 letterbox 留白（模糊背景填充），**以便**视觉更丰满专业

### 3.2 阶段2（媒体化文件呈现，含后端）

- **作为**网盘用户，**我希望**文件夹显示 3D 立体封面并预览内含内容，**以便**不点开就知道文件夹里有什么
- **作为**网盘用户，**我希望**视频文件显示帧缩略图和播放按钮，点击即播放，**以便**像媒体库一样浏览视频

#### 阶段2 补充：工具栏区视觉层次修正

> 阶段1 实现后用户反馈：文件列表上方区域（工具栏 + 面包屑条）太白刺眼。

**根因**（阶段1 实证）：
- `FileToolbar.tsx:47` 工具栏用 `bg-surface/80`，浅色模式 surface=纯白(255 255 255)
- `FileManager.tsx:24` 顶部条同样 `bg-surface/80`
- 主内容区 `bg-bg`=250 250 249（极浅灰），工具栏白上加白，缺乏层次区分

**修复方向**（阶段2 实现时定）：
- 工具栏/顶部条背景由 `bg-surface/80` 改为 `bg-bg` 或加极浅 tint，与纯白列表区拉开层次
- 参照 PikPak：工具栏与列表区有微妙背景差 + 底部 `box-shadow: 0 1px 0 rgba(0,0,0,0.08)` 极淡投影分隔（非硬边框）
- 面包屑区同步处理

**验收**：工具栏区不再纯白刺眼，与列表区有清晰但不突兀的层次区分，浅色/深色双模式一致。

#### 阶段3：Bug 修复（用户反馈）

> 阶段1/2 实现后用户反馈的两个 bug，纳入阶段三处理。

**Bug 1：首页顶部白色文字看不清**

- 根因：阶段1 将 brand-gradient 从 `#0d0d0f` 改为 `rgb(var(--bg))`（浅色模式极浅灰底），但 HomePage hero 区文字仍是 `text-white`（白字），浅底白字不可读
- 影响文件：`src/pages/HomePage.tsx:111,117,122,156,158`（brand-gradient 消费者，阶段1 漏适配）
- 修复方向：hero 区文字 `text-white` -> `text-fg`（深色文字），`text-muted` 保留；快捷卡片的 `text-white` 在彩色渐变卡片上保持（卡片本身是深色渐变）

**Bug 2：文件列表网格模式超出屏幕无法滚动**

- 根因：`AppLayout.tsx:55` main 容器为 `overflow-auto`，当内容超出视口时 main 自身滚动，但 FileManager `h-full` 取的是 main 的内容高度（会撑开）而非视口高度，导致 `FileBrowser:762` 的 `flex-1 overflow-auto` 没有获得有界高度，内部无法产生滚动条
- 影响文件：`src/components/layout/AppLayout.tsx:55`
- 修复方向：main `overflow-auto` -> `overflow-hidden`，让内部 flex-1 overflow-auto 容器处理滚动（或给 flex 链路补 `min-h-0`）
