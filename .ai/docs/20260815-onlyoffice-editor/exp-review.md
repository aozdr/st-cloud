## 用户路径核查

### 主路径：编辑文档

```
文件列表（FileBrowser）
  → 选中 docx/xlsx/pptx → 右键/工具栏「在线编辑」
  → 新页面加载 OnlyOffice（loading 态）
  → 编辑（自动保存指示）
  → 关闭/返回文件列表 → 列表刷新（新大小/新版本）
```

### 分支路径

| 场景 | 应有状态 | 评审结论 |
|------|---------|---------|
| 无编辑权限点「在线编辑」 | 按钮隐藏；打开为只读 | ✅ |
| OnlyOffice 不可达 | 明确错误提示 + 回退只读预览按钮 | ⚠️ 必改：错误态文案与回退路径必须在设计里实现 |
| 编辑中他人删除/移动/重命名 | 操作被拒并提示「文件正在编辑中」 | ✅ |
| 移动端（PWA） | iframe 可用、工具栏可操作 | ⚠️ 必改：移动端最小宽度适配（OnlyOffice 窄屏按钮折叠） |
| 保存失败 | 前端提示「保存失败，可稍后重试或下载编辑」 | ✅ |

## 交互与状态要求（写入设计）

1. 加载态：编辑器 iframe 就绪前显示骨架/进度，禁止白屏
2. 错误态：OnlyOffice 加载失败 → 弹窗说明 + 「以预览打开」回退按钮
3. 保存态：OnlyOffice 自带保存指示，后端不做额外进度条；保存成功后前端刷新文件元数据
4. 权限态：编辑按钮按权限显隐；只读打开时无编辑工具栏
5. 编辑入口：右键菜单 + 工具栏按钮进入编辑；**双击保持现有预览**（避免打断既有习惯）
6. 编辑中保护：删除/移动/重命名被拒时提示「文件正在编辑中，请关闭编辑器后重试」
