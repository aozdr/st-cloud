# 测试用例

| 编号 | 场景 | 预期 |
|---|---|---|
| R01 | 管理员保存并读取根目录规则 | 返回本空间规则，节点 ID 为 0 |
| R02 | 同租户空间 A、B 均有根规则，重存 A | B 的规则不变；A/B 成员只获得所属空间的根权限 |
| R03 | 普通成员尝试写根规则 | 拒绝且原规则不变 |
| R04 | 正常节点的 fresh 权限解析、20 层深目录的常规解析 | 父链到根后包含根规则，且请求内读取可复用 |
| R05 | 缺失/跨空间/循环父链 | fresh 解析为空，不应用根规则 |
| R06 | 正数跨空间节点保存或读取 | 继续拒绝 |
| R07 | 根目录内容接口传 `parentId=null` 或 `0` | 均使用本空间根规则授权，其他空间的规则不参与 |
| R08 | 普通权限解析传其他空间节点或断链节点 | 拒绝授权，不能叠加本空间根规则 |
