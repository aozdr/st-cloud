# 架构设计评审（20260820-ui-refactor）

## 方案概述

- 保持 React 18 + Vite + Tailwind 技术栈不变，不引入 UI 框架。
- 采用「CSS 变量重映射 + 组件类名微调」策略：主色/中性色/语义色/圆角/阴影收敛到规范 Token，避免重写全部组件。
- 两视图收敛（list/grid）：删除 card 视图组件，降低维护面。

## 评审结论

| 维度 | 结论 |
|------|------|
| 影响范围 | 前端展示层，后端/数据零改动 |
| 依赖 | 无新增依赖，仅字体加载换 Inter（离线回退系统字体） |
| 性能 | 仅样式与结构变化，无新增运行时开销 |
| 可访问性 | 保留 aria-label、Escape、焦点环、键盘导航 |
| 兼容性 | 三端共用组件，未改环境检测逻辑 |
| 深色模式 | 保留既有 dark token，新 Token 提供 dark 变体 |

## 遗留风险

- 次级页面（admin/team/transfer/sync）保留少量旧色类，由 stone 重映射兜底，本轮不做页面级深改。

## 结论

架构方案成立，可进入程序设计。
