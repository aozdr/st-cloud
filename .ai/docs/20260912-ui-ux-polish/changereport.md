# 变更报告：st-cloud UI/UX 视觉与交互收敛

任务：`20260912-ui-ux-polish`

## 背景

依据两份用户提供的 UI 优化计划，收敛共享 Web UI 与 Electron 入口，重点处理文件管理高频交互、移动端主导航、传输页和主题视觉层级。

## 已执行变更

### Design System 与 App Shell

- Light/Dark 主题 token 收敛到计划中的背景、surface、边框、文字和品牌蓝。
- Sidebar 默认宽度调整为展开 `224px`、折叠 `64px`，导航改为“文件/工具/桌面端/管理”分组；保留权限过滤和拖拽排序。
- TopBar 高度调整为 `60px`，搜索框改为“搜索文件或内容”，保留 Ctrl/Cmd+K，移除 Ctrl/Cmd+F 全局拦截及固定搜索按钮。
- 普通按钮移除 scale active 反馈；普通内容面与卡片移除重阴影、渐变和玻璃效果。

### 文件管理

- FileToolbar 将选择态拆为已选摘要、高频操作和“更多”菜单；排序、刷新、视图切换保留。
- 瀑布流只在当前集合全部为图片时提供；旧偏好在不满足条件时自动回退网格，不再静默丢弃非图片文件。
- 表格行、收藏、更多、选择按钮补充 `group`、`group-focus-within`、selected 状态和可见 focus ring。
- 列表表头使用 `surface-2`，列表/网格内容使用 `surface`；网格文件信息左对齐，普通文件操作使用浅色圆形按钮。

### 页面与运行时入口

- 首页问候、存储信息、快捷分类收敛；删除独立“最近文件”区块，保留“最近访问”和有数据时的收藏。
- 传输页删除 KPI 卡片和页面内悬浮窗按钮，保留任务列表、暂停/恢复、历史、设置和紧凑速度摘要。
- 同步页所有用户可见英文文案改为中文。
- Admin、Login、分享安全面板改用主题 token，Login 去除营销式渐变/发光效果。
- Web/Capacitor 移动 Tab 改为“首页/文件/搜索/更多”；Electron 不渲染 MobileTabBar。
- Electron 主进程不再启动 mini window，不再展示托盘“显示传输悬浮窗”，托盘双击改为打开主窗口传输管理；底层 mini-window/preload/IPC 文件按用户确认保留。

## 影响边界

- 未修改后端 API、数据库、权限语义、同步协议、上传下载和预览内核。
- 未新增运行时依赖。
- 用户确认的三项设计决策已记录在 `design.md`：保留 mini-window dead code、移动 Tab 使用“搜索”、删除首页独立“最近文件”。
