# 测试用例：st-cloud UI/UX 视觉与交互收敛

> 任务 ID：`20260912-ui-ux-polish`
> 设计输入：`.ai/docs/20260912-ui-ux-polish/design.md`

## 一、测试目标

验证视觉 token、文件管理高频交互、运行环境入口、桌面传输体验和响应式布局；确认 API、权限、文件操作与同步行为不回归。

## 二、测试范围

- 静态检查：硬编码颜色、遗留 Ctrl+F、悬浮窗用户入口、瀑布流过滤逻辑。
- Web：lint、build、hash contract test。
- Desktop：lint、test、build:main。
- 手工/浏览器检查：`/login`、`/`、`/files`、`/transfers`、`/sync`、`/admin`，并覆盖四种视口。

## 三、测试环境

```
环境：Windows / PowerShell，Node.js 项目本地依赖
Web：st-web
Desktop：st-desktop
后端：不要求启动；使用现有 mock/登录态或静态页面检查
视口：1440x900、1280x800、960x600、390x844
主题：浅色、深色
```

## 五、P1 与视觉验收用例

### 用例 TC-009：Design System 与 App Shell

在 1440x900、1280x800、960x600、390x844 浅色/深色分别检查：Sidebar 224/64px、TopBar 60px、内容面白色、边框低对比、主色统一、普通文件列表无 shadow、无大灰底/渐变/玻璃效果。

### 用例 TC-010：首页信息收敛

检查 greeting 约 20px、storage 为紧凑信息、快捷分类约 72~80px；有数据时显示收藏和最近访问，不再出现独立“最近文件”重复区块。

### 用例 TC-011：网格与文件卡片

检查普通文件名/大小左对齐、文件夹不放在巨大空白缩略图中、图片/视频可使用缩略图/播放 overlay、普通文件 hover 操作为浅色按钮、选中态为浅蓝背景/outline。

### 用例 TC-012：Admin 主题一致

浅色/深色打开 `/admin`，检查背景、surface、border、text、active 色来自语义 token；1280px 无页面横向溢出；导航字体、icon、间距与主 Sidebar 一致。

### 用例 TC-013：Login 产品化

Web 与 Electron 分别打开 `/login`：无渐变标题、发光 bullet、超大营销 Hero；Electron 文案更克制，服务器设置可达；登录/注册字段、错误提示、跳转行为不变。

### 用例 TC-014：Sync 操作收敛

打开同步根，检查默认行只突出状态与启动/停止/更多；策略、选择性同步、删除在展开详情或更多中仍可用；无操作越界。

## 七、静态回归检查

- `rg` 确认 TopBar 不再注册 Ctrl+F 全局 handler。
- `rg` 确认 TransferManager/AppLayout/main 不再创建、显示或提供悬浮窗用户入口。
- `rg` 确认 FileGrid 不再用 `files.filter(image)` 作为普通瀑布流唯一数据源。
- `rg` 检查新增 UI 代码未引入新的无语义 `bg-[#...]`、`text-[#...]`，文件类型/状态色例外需记录。
- 检查 `git diff --check` 无空白错误；`git status` 中不覆盖用户既有未跟踪文档。
