# 安全审查记录：历史版本预览

> Task: `20260910-version-preview`｜reviewer / security｜日期：2026-09-10
> 触发条件：涉及文件访问与越权防护，条件项激活

## 一、结论

通过。越权、跨租户、链接时效三项均按现有安全基线实现，未引入新的数据暴露面。

## 二、审查项

| 维度 | 检查内容 | 结果 |
|------|---------|------|
| 越权访问 | 先 `getFileNode(nodeId)` 校验节点存在/未删除/可访问，再校验 `version.file_node_id == nodeId`；仅凭 `versionId` 无法取对象 | 通过（TC-04 覆盖） |
| 权限传播 | 节点无权限时异常直接抛出，不返回预览结果（TC-06） | 通过 |
| 租户隔离 | `FileNodeMapper` / `FileVersionMapper` 走 MyBatis-Plus 租户拦截；跨租户查询取不到记录 → 按「版本不存在」处理 | 通过 |
| 信息泄露 | 错误文案仅「版本不存在」「读取文件内容失败」，不返回对象存储路径、MD5、租户 ID | 通过 |
| 链接时效 | 复用 `StorageService.generateDownloadUrl`，预签名 1 小时；缩略图预签名同为 1 小时，无长期公网链接 | 通过 |
| 认证要求 | 端点位于 `PreviewController` 类级 `@PreAuthorize("isAuthenticated()")` 之下，未开放匿名访问 | 通过 |
| 分享链路 | 分享访问仍只预览当前版本，未把版本能力挂到匿名分享接口 | 通过（未改动 ShareController） |
| 输入校验 | 路径参数为 `Long`，非法值由框架拒绝；无 SQL 拼接（MyBatis-Plus 主键查询） | 通过 |
| 审计 | 只读预览不写审计日志，与现有普通预览一致，避免审计噪音 | 通过 |

## 三、残余风险

- 拥有节点读权限的用户可预览全部历史版本（含他人上传的旧版本内容）。这与「文件版本属于该文件」的现有权限模型一致；如需按版本粒度管控，需单独立项。
- 历史版本不支持 Office 在线预览，该限制以提示文案告知，不构成安全风险。
