# UI/UX 设计文档：团队空间 P2 高级协作

> 归属 exitCriteria: EXP_DESIGN（依赖 REQ_ANALYSIS）

## 1. P2-1 文件锁定

**文件列表展示：** 锁定文件行显示锁定图标 🔒 + 锁定人昵称（hover 显示剩余时间）。

**锁定操作入口：** 文件右键菜单/操作栏新增"锁定"按钮（编辑者以上可见），已锁定文件显示"解锁"。

**锁定弹窗：**
```
┌─ 锁定文件 ───────────────────┐
│  确定锁定「设计稿.fig」？     │
│  锁定后其他人无法修改此文件   │
│                              │
│  锁定时长：                   │
│  ○ 1小时  ○ 6小时  ● 24小时  │
│  ○ 永久                      │
│                              │
│         [取消]  [锁定]        │
└──────────────────────────────┘
```

**锁定拦截提示：** 操作被锁定文件时 Toast 提示"该文件被 XX 锁定，无法操作"。

## 2. P2-2 自定义角色

**角色管理入口：** 成员管理弹窗新增"角色管理"分区/按钮。

**角色管理弹窗：**
```
┌─ 角色管理 ─────────────────────────────┐
│                          [+ 新建角色]   │
├──────────────────────────────────────────┤
│  管理员（预设）        启用              │
│  编辑者（预设）        启用              │
│  查看者（预设）        启用              │
│  ── 自定义角色 ──                        │
│  审计员      [编辑] [停用] [删除]       │
│  访客编辑    [编辑] [停用] [删除]       │
└──────────────────────────────────────────┘
```

**新建/编辑角色弹窗：**
```
┌─ 新建角色 ──────────────────────────────┐
│  角色名称：[审计员           ]           │
│                                          │
│  权限项：                                │
│  ☑ 查看文件    ☑ 下载文件               │
│  ☐ 上传文件    ☐ 删除文件               │
│  ☐ 重命名      ☐ 移动                   │
│  ☐ 分享        ☐ 管理成员               │
│  ☐ 管理设置                              │
│                                          │
│                  [取消]  [保存]          │
└──────────────────────────────────────────┘
```

**邀请成员角色选择：** 下拉中预设角色在上，自定义角色在下，用分隔线区分。

## 3. P2-3 外部协作者

**成员列表展示：** 外部成员行显示"外部"标签（蓝色）+ 有效期。

**标记外部协作者：** 成员行操作菜单新增"标记为外部"按钮。

**外部协作配置：** 成员管理弹窗新增"外部协作设置"开关。

```
┌─ 外部协作 ──────────────────────────────┐
│  允许外部协作者    [开关 ON/OFF]         │
│  开启后可邀请组织外人员加入此空间        │
└──────────────────────────────────────────┘
```

**设置有效期弹窗：**
```
┌─ 设置有效期 ────────────────────────────┐
│  为外部协作者「张三」设置访问有效期      │
│  有效期：[2026-09-01 📅] 或 [永久]      │
│                  [取消]  [保存]          │
└──────────────────────────────────────────┘
```

## 5. 交互细节
- 锁定/解锁/角色管理/外部标记均用现有弹窗模式
- 统计图表用 Recharts 的 PieChart + BarChart
- 统计 Tab 切换时懒加载统计数据
- 角色权限勾选用 Checkbox 组件
