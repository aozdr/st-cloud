# 程序设计文档：文件页信息架构与操作可发现性（P1-A）

> 任务 ID：`20261017-ui-ux-p1-a`
> 前置：P0-A（token/移动端/状态）、P0-B（弹窗可访问性）已完成。

## 一、目标

文件页当前的阅读顺序是“工具栏 → 面包屑”，用户先看到操作，后看到位置；“新建”是 primary，“上传”是 ghost；移动端工具栏右侧控件被裁切；触屏行操作依赖 hover。P1-A 修正这四件事。

## 二、方案

### 2.1 页面标题与层级

`FileBrowser` 的信息带调整为：

```text
标题 + 项数 + 图标尺寸
面包屑（文件夹/根目录；分类页隐藏）
工具栏（上传 primary / 新建 secondary / 排序 / 刷新 / 视图）
文件列表
```

- 标题计算：
  - `categoryLabel` 存在 → 使用分类名；
  - `parentId === '0'` → “全部文件”；
  - 否则 → `pathSegments` 最后一段名称，回退“全部文件”。
- 桌面端标题与面包屑同一行；移动端标题一行、面包屑一行，避免路径被挤压。
- 分类页隐藏面包屑（分类不是路径）。
- 图标尺寸切换保留在标题行右侧（仅 grid 视图）。

### 2.2 工具栏主次

- `FileToolbar`：上传按钮改 `btn-primary`，文案响应式（`上传` / `上传文件`）；新建改 `btn-secondary`（保留下拉）。
- 排序下拉、文件夹优先开关在 `<md` 隐藏，保留刷新与视图切换；避免移动端右侧裁切。
- 选择态批量操作保持原逻辑；移动端仍由 `MultiSelectBar` 主导。

### 2.3 触屏操作可发现性

- `FileTableView` 行内收藏/更多：`opacity-0` 改为 `<md` 常显；按钮从 32px 提到 36px。
- `FileGrid` 收藏按钮：`<md` 常显（已收藏仍常显）。
- 表格复选框视觉仍 16px，但外圈按钮加 padding 到 ≥36px 命中区。
- `FileBrowserPagination` 上一页/下一页 `min-h-9`，页码输入 `h-8`。
- `FileBreadcrumb` 路径编辑按钮 `w-8 h-8`；根目录按钮 `min-h-8`。
- 不改变桌面 hover 行为；桌面仍以 hover 减少噪声。

### 2.4 不做的事

- 不新增筛选器；规范中的“筛选”留到有真实后端过滤能力时再做。
- 不改表格 ARIA/grid 语义（P1-B）。
- 不改 PageHeader 之外的全站页面。

## 三、风险

| 风险 | 缓解 |
|---|---|
| 标题/面包屑增加纵向占用 | 移动端两行紧凑布局；桌面同行 |
| 上传/新建调换导致误点 | 文案与图标保持清晰；上传按钮不触发放置区 |
| 行操作常显增加噪声 | 仅 `<md` 常显，桌面仍 hover |
| 工具栏隐藏排序影响移动效率 | 移动端保留视图/刷新；排序可在 P1-B 放入更多菜单 |
| 无后端时无法验证 | 启动本地 dev 后端 + Vite + CDP；否则记录限制 |

## 四、测试计划

1. `npm run lint`、`npm run build`、`git diff --check`。
2. 浏览器 1440：根目录/文件夹/分类标题与面包屑；上传 primary；行操作 hover。
3. 浏览器 390：标题/面包屑两行；工具栏无裁切；行收藏/更多可见；pageOverflow=0、tableOverflow=0。
4. 静态扫描：`btn-primary` 上传、`hidden md:flex` 排序组、`max-md:opacity-100` 行操作。
5. 回归：文件选择、右键菜单、分页、视图切换。
