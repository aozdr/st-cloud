# 测试用例 - 星云盘移动端

> 输出标准：`docs/newList/ai-test-case-standard.md`
> 关联需求文档：`.ai/docs/20260809-mobile-pwa-capacitor/requirement.md`
> 编写时机：程序设计评审通过后、开发开始前
> 落盘路径：`.ai/docs/20260809-mobile-pwa-capacitor/testcases.md`

# 一、测试目标

验证:
- 移动端布局响应式正确性(18 页面无横向滚动)
- PWA 安装与离线能力
- Capacitor 原生能力(下载落盘/相册上传)
- 环境降级链(capacitor/electron/web)正确性
- 触摸交互(长按/多选/ActionSheet)
- 编译通过

# 二、测试范围

- 前端测试:响应式布局 + 交互组件 + PWA + Capacitor 集成
- 兼容测试:Chrome 移动模拟 + 安卓真机 WebView
- 接口测试:后端零改动,仅回归现有 API 移动端可用性
- 构建测试:npm run build + Capacitor 打包

# 三、测试环境

```
环境：Chrome DevTools 移动模拟(iPhone SE/Pixel 7) + 安卓真机(Android 8+/WebView Chromium)
数据库：stcloud(MySQL,现有)
缓存：Redis(现有)
依赖服务：st-api:8080 + S3 + ES(现有)
版本：st-web build 产物 + Capacitor android 工程
```

# 五、测试覆盖要求

## 功能覆盖
- 正常流程:导航/浏览/操作/下载/上传/分享
- 边界条件:空列表/深层目录/大文件
- 异常输入:弱网/断网/权限拒绝/不兼容格式

## 权限覆盖
- 未登录:分享访客页
- 普通用户:文件/分享/团队/收藏
- 管理员:含系统管理页移动端
- 资源拥有者:操作自有文件

## 数据覆盖
- 空数据:空列表 EmptyState
- 大数据:长列表滚动
- 重复数据:重复检测页移动端

# 六、接口测试

后端零改动,接口测试为移动端回归(验证 CORS + JWT 对接):
- `/api/auth/login` - 移动端登录获取 token
- `/api/files/*` - 文件列表/操作
- `/api/share/access/*` - 公开分享访问(CORS 白名单)
- 验证:Authorization header 自动附加,CORS 放行移动 origin
