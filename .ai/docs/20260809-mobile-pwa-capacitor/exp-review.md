# 体验评审报告 - 星云盘移动端(UI/UX)

> 归属标准：EXP_DESIGN（dependsOn: REQ_ANALYSIS）
> 落盘路径：`.ai/docs/20260809-mobile-pwa-capacitor/exp-review.md`
> 输入：Loop State 快照 + artifacts.prd + artifacts.uiSpec
> 评审维度：用户路径 / 交互逻辑 / 操作效率 / 状态反馈完整性

## 评审结论：PASS(附优化建议)

移动端方案在用户路径与交互逻辑上整体合理,核心场景(浏览/下载/分享/上传)单手可达。以下为评审细节与优化建议,建议在实现阶段采纳。

## 一、用户路径评审

### 路径清晰度 ✅

- **浏览文件**:底部 Tab"文件" -> FileManager -> 长按操作,路径清晰,2 步可达核心操作
- **分享生成**:长按文件 -> ActionSheet"分享",与桌面右键路径对等,符合预期
- **分享访问**:`/share/:shareCode` 公开页移动端适配,访客无需登录,路径无冗余
- **PWA 安装**:浏览器"添加到主屏幕"是标准 PWA 路径,无需额外引导

### 建议优化

- **"我的"Tab 语义**:"我的"点击触发抽屉,但抽屉内是"次级导航"(收藏/分享/团队/回收站)而非"个人中心"。建议:
  - 方案 A(推荐):底部 Tab 第 4 项改为**"更多"**(Menu 图标),语义更准确,降低"个人中心"误解
  - 方案 B:保留"我的",但抽屉顶部放用户信息(头像/用户名/存储空间),下方放次级导航,兼顾个人中心与导航
- **搜索入口**:移动端隐藏搜索框、保留搜索图标按钮(已有 `sm:hidden`),路径合理。建议搜索页移动端搜索框置顶固定,历史记录下方,避免键盘弹出遮挡
- **上传入口**:桌面端 Sidebar 有"上传"按钮,移动端 Sidebar 是抽屉。建议底部 Tab"文件"页顶部加浮动上传 FAB(Floating Action Button),或在 ActionSheet 内提供"上传文件"入口,确保上传路径可达

## 二、交互逻辑评审

### 触摸交互 ✅

- **长按替代右键**:500ms 长按触发 ActionSheet,符合移动端习惯
- **触控热区≥44px**:uispec 已明确 `min-h-[44px]`,达标
- **键盘快捷键禁用**:`useFileKeyboard` 移动端不绑定,避免误触

### 建议优化

- **长按与点击冲突**:长按 500ms 期间若手指移动(滚动列表)应取消触发,避免误触 ActionSheet。实现需监听 touchmove 取消
- **ActionSheet 关闭**:遮罩点击 + 下滑关闭,建议增加"点击空白处关闭"(与遮罩等价但用户认知更直觉)
- **多选模式**:桌面端 Ctrl/Shift 多选,移动端缺失。建议长按进入多选模式后,顶部出现操作栏(全选/下载/删除/分享),单击切换选中。这是移动端文件管理的核心缺失,强烈建议 P0 补齐
- **下拉刷新**:uispec 标注"可选",建议提升为 P0,移动端文件列表无下拉刷新会显得"卡"

## 三、操作效率评审

### 效率 ✅

- 底部 Tab 4 项主导航,不超载(>5 项效率下降)
- 长按 ActionSheet 集中文件操作,减少跳转

### 建议优化

- **批量操作**:如上,移动端多选模式是效率关键,否则逐个长按删除/下载效率极低
- **面包屑**:移动端"返回箭头 + 当前文件夹名"正确,但深层目录需多次点击返回。建议长按返回箭头弹出路径面包屑快速跳转(可选,降级为 P1)
- **传输管理入口**:底部 Tab"传输"直达,效率高。但纯浏览器(无 Capacitor/Electron)下传输在后台不可用,需在 Tab 上明确提示"前台运行中",避免用户切走后以为在传

## 四、状态反馈完整性评审

### 状态覆盖 ✅

- Loading:列表骨架屏(shimmer 已有)
- Empty:EmptyState(SVG 插图,已有)
- Error:toast 提示
- Success:下载完成 toast + 系统通知(Capacitor)

### 建议优化

- **弱网状态**:断网时 PWA 壳层可打开,但数据请求失败需明确区分"网络异常"与"空数据"。建议网络错误时显示重试按钮而非 EmptyState
- **传输后台中断**:安卓杀进程后传输中断,重进 App 需恢复提示"上次传输未完成,是否继续"。需前端从服务端查询任务状态
- **权限拒绝反馈**:相机/相册权限拒绝时,引导去系统设置开启,文案需具体("需要相册权限才能上传照片,请到设置 > 应用 > 星云盘 开启权限")
- **安装引导**:PWA 首次访问可提示"添加到主屏幕获得更好体验",但不要打扰(显示一次,localStorage 记忆)

## 五、云盘重点项评审

### 文件管理效率 ✅
单列卡片 + 长按 ActionSheet 基本满足,但**多选模式缺失**是最大效率短板(见上)。

### 上传下载体验 ✅
- 上传:FAB/ActionSheet 入口 + 进度浮窗(已有 TransferFloatingWidget),移动端需确认浮窗不遮挡底部 Tab
- 下载:Capacitor 落盘 + Share 提示,体验优于浏览器下载

### 分享流程 ✅
长按 -> ActionSheet"分享" -> ShareDialog,与桌面一致。分享访客页移动端适配已纳入。

### 权限提示 ✅
RBAC 复用,无新增权限码。权限不足时复用现有提示。

## 六、优化建议汇总(供实现阶段采纳)

| 编号 | 建议 | 优先级 | 说明 |
|------|------|--------|------|
| UX1 | "我的"Tab 改"更多"或抽屉顶部加用户信息 | P0 | 语义准确 |
| UX2 | 文件页增加上传 FAB | P0 | 上传路径可达 |
| UX3 | 移动端多选模式 | P0 | 效率关键,长按进入多选 |
| UX4 | 下拉刷新 | P0 | 移动端列表标配 |
| UX5 | 长按 touchmove 取消 | P0 | 避免误触 |
| UX6 | 传输 Tab 后台运行提示 | P1 | 管理预期 |
| UX7 | 弱网重试按钮 | P1 | 区分网络错误与空数据 |
| UX8 | 传输中断恢复提示 | P1 | 从服务端恢复任务状态 |
| UX9 | 权限拒绝引导文案 | P1 | 具体到设置路径 |
| UX10 | PWA 安装引导(显示一次) | P2 | 提升安装率 |

## 验收结果：PASS

方案用户体验整体可行,优化建议(尤其 UX1–UX5 的 P0 项)建议在实现阶段纳入。不构成阻塞。
