# 整改 UI 需求规格汇总

修订：design-v1。UI 条件适用，仅说明最小功能和状态变化，沿用当前界面。

- [CR-02 角色选择与成员管理](CR-02/uispec.md)：预设与自定义字符串 ID、成员角色修改、邀请和 ACL 回显、加载/失败/失权状态。
- [CR-07 图片预览降级](CR-07/uispec.md)：格式能力分开、胶卷 fallback、原图授权、历史版本与分享边界。
- CR-01：复用既有未认证/重新登录流程，不新建登录页面；不能自动无限刷新已失效版本。
- CR-03：复用既有复制失败提示，不在本项设计新复制交互。
- CR-04：复用同步历史/错误状态显示恢复副本位置、无法判定的历史文件和客户端/服务端能力不匹配。暂停、失败和恢复状态必须可见；不增加独立恢复管理产品。
- CR-05：主图流计次、缩略图不计次，修正过时说明；不新增下载计费 UI。
- CR-06：沿用游标无效/过期后重新搜索反馈，不自动把第一页追加到旧分页列表。

自检覆盖信息、操作和错误状态；没有视觉重设计、浏览器执行或体验验收。本轮由主线程完成，不能称为独立体验评审。
