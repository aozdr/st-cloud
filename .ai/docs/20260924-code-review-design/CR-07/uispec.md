# CR-07 图片预览降级交互

修订：design-v1。保持 PreviewModal 当前主图、文件名、左右导航和胶卷布局。

| 场景 | 主图 | 胶卷 |
|---|---|---|
| 支持且成功 | 当前缩略/预览图 | sm 缩略图 |
| WebP/SVG | 用户打开时用授权原图 img；浏览器失败则提示不可预览 | 通用图片图标，不自动下载原图 |
| 超限、坏文件、暂无解码容量 | 图标和“暂无法预览，可下载原文件”；下载遵循原权限 | 图标，文件名和导航保留 |
| 历史版本失败 | 标明历史版本不可预览，不展示当前版本替代 | 不混用当前版本缩略图 |
| 分享无权限/次数用完 | 显示已有访问限制，不以 fallback 绕过 | 原有权限限制仍生效 |

图片 onError 进入稳定失败状态，禁止 src 来回切换循环。切换文件可重新初始化状态；主图提供一次显式重试操作，胶卷不自动密集重试。图标保留 alt/可访问名称，选中状态和键盘导航不变。

分享胶卷不消耗下载次数；用户打开原图/流可能消耗，文案/注释不能声称免费。错误提示避免暴露存储路径和内部异常。设计为主线程文本自检，无浏览器验收或生产 UI 修改。
