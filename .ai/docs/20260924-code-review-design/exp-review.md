# 设计阶段体验自检材料

修订：design-v1；执行者：主线程；方式：文本与源码对照自检。

用户已明确要求“不要开子线程，你自己完成”，因此不执行独立 Agent 体验评审。本文不是运行后的 EXP_ACCEPT，不宣称浏览器验收通过。

| 范围 | 核对内容 | 设计结论 |
|---|---|---|
| 角色管理 | 预设/自定义选项、保存状态、失效角色、邀请、所有者保护、字符串 ID | CR-02 uispec 与 design 一致 |
