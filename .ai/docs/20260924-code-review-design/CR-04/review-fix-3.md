## 决策与实现

- 同路径 CREATE/UPDATE 的内容校验使用当前节点详情中的 fileSize、fileMd5、updatedAt，不使用历史日志的内容快照。保留日志身份与事件类型；路径变化仍走已有对账流程。fileSize 通过既有安全大小解析函数处理，nodeId 始终为字符串。
- 下载期间内容再次变化时仍由长度和 MD5 校验拒绝写入，不固化游标；下一轮重新读取当前详情后重试。未取消完整性校验。
- keep_both 只有两份副本均成功后才提交原文件的新节点/MD5 基线。失败保留原基线、记录 error 并抛出，下一轮重复事件仍能识别并重试冲突。已有失败临时副本保留逻辑继续有效。
