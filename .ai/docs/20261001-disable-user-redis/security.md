# 安全自检 disable-redis-code-r1

执行者 workflow-manager，自检，非独立安全审查。用户清理范围“独占key”“不能直接从key拿到的内容都不用处理”已落实。

生产新增服务只SCAN key与DELETE；没有GET、KEYS、读取集合/Hash、Lua读内容、FLUSHDB/FLUSHALL。用户ID为正Long，无法注入glob/正则。固定用户段全匹配，不把ID出现在节点或空间段当成用户归属；非法/共享/未知格式保留。既有refresh精确DELETE不读取内容。

主库status/security_version仍用于鉴权，Redis扫描失败不能使旧会话恢复；失败后提交已发生，重复停用重试。事务回滚没有清理副作用。共享编辑集合、锁、幂等/防重放、文件大小/可访问缓存和分享限流不处理。测试实际证明其他用户原会话有效。

真实Redis连接仅127.0.0.1:16381的新临时容器，独立H2固定夹具；没有读取开发Redis、没有停用实际账号。首轮旧断言失败把隔离临时JWT输出到JUnit失败信息，已脱敏本轮生成日志/报告并保留失败审计；复验成功，不导出真实账号凭据。临时Redis容器核对本任务label后停止；运行后端精确核对由主线程创建的命令/监听后替换。

结论：本范围无阻断风险；不宣称终止已进入业务的请求或跨库原子删除。
