> 验证环境：Web 端为主；涉及 Electron / Capacitor 的条目标注。

## 1. 数据加载与视图基线

- [ ] 首次进入目录：先骨架屏/加载中，随后列表出现；无报错、无重复请求（Network 面板 `/file/list` 一次）。
- [ ] 切换文件夹：`parentId` 变化后复位到第 1 页，只发一次请求，列表原地更新不闪烁。
- [ ] 加载失败：显示「加载失败」空态 + 重试按钮，点重试可恢复。
- [ ] 空目录：显示 `EmptyState`（新建文件夹 / 上传按钮按权限显隐）。
- [ ] 刷新（工具栏刷新按钮）：图标旋转，列表淡入，请求发出。
- [ ] 深色/浅色主题切换：列表、工具栏、对话框配色正常。

## 2. 排序与视图

- [ ] 列表视图排序：点表头「名称/大小/修改时间」切换排序，再次点击同列切换升/降序，箭头方向正确。
- [ ] 网格视图排序：右下角排序下拉切换字段，升/降序按钮生效。
- [ ] 文件夹优先开关：开启后文件夹置顶，关闭后混排。
- [ ] 列表 / 网格视图切换：切换后保留排序、收藏置顶。
- [ ] 网格图标大小切换（小/中/大）：列数与图标尺寸随之变化。
- [ ] 排序/视图/iconSize 持久化：刷新页面后保留（localStorage）。

## 3. 分页

- [ ] 总数显示正确；每页条数切换（50/100/150/200）后回到第 1 页。
- [ ] 页码跳转：输入数字回车/失焦生效，超范围钳制到 1..totalPages。
- [ ] 上一页/下一页：到位后对应按钮禁用。
- [ ] 翻页后滚动位置/选中状态：无残留选中；换页不触发整页重载。

## 4. 文件选择与多选

- [ ] 单击选中：单选；再次单击已选中的唯一项取消选中。

- [ ] 顶部工具栏/路径区域不触发框选。
- [ ] 移动端多选模式：长按进入多选，底部 `MultiSelectBar` 出现，可全选/下载/删除/取消。
