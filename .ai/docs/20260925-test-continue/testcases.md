# 本轮执行用例

1. TC07-01：真实图片渲染为可解码 JPEG，检查边长；现有入口尺寸变体未覆盖，预计 PARTIAL。
2. TC07-02/06：WebP/SVG 及伪装文本被拒，存储读取不发生或读后拒绝；普通主图预览由其他服务负责，预计 PARTIAL。
3. TC07-03：同一合法图片以配置阈值 B+1、B、B-1 形成 HEAD 长度边界；失败路径不得下载。预览服务缓存写入尚未覆盖，记 PARTIAL。
4. TC07-04：HEAD 显示大小未超而流大于 B；流硬上限中断，源流关闭，预计 PARTIAL（对象增长和解码阶段需要另测）。
5. TC07-07：许可 C=1 时第一个请求阻塞读取；第二个快速拒绝；放行后第三个成功，预计 PARTIAL（单实例限制）。
6. TC07-08：读取异常后许可释放并可成功再请求；预计 PARTIAL（其他故障点待测）。
7. TC07-09：0/负配置初始化失败、正值生效，预计 PASS。
8. TC04-08：当前同步引擎直接消费字符串大游标；数字大游标、缺失/无效游标、非法 changes/hasMore、缺失/错误 scopeProjectionVersion、hasMore 不前进均拒绝且不固化游标。已按验收点覆盖，记 PASS。
9. TCDB-10：相邻大游标通过真实 SQLite 持久化，重建数据库实例后继续分页；hasMore 不前进拒绝且不改库，记 PASS。
10. TC05-01：五线程通过流下载前置条件并在源流打开时同步释放，实际 H2 原子 UPDATE 最多授予一次；需 MySQL 多实例补测，记 PARTIAL。
11. TC05-02：同一 H2 实例内一个预签名 URL 与四个流同时竞争最后一次额度，最多一个授权；需双实例 MySQL 补测，记 PARTIAL。
12. TC05-05：源对象打开失败与预签名生成失败均不占额度、无成功响应，记 PASS。
13. TC05-06：源流打开后另一个 URL 申请占用最后额度；当前流闭合，不调用输出流、不设置成功文件长度，count 不超额，记 PASS。
