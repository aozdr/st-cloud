# 缩略图链路 UI 规格

## 适用范围

本轮 UI 影响仅限分享胶卷图片的资源来源，不改变布局、尺寸、交互文案、颜色或响应式断点。

## 规则

- 胶卷图片继续使用当前 `img` 组件、加载态和失败态。
- `src` 从分享原图流地址切换为分享授权缩略图地址，并继续携带 `shareCode`、`nodeId` 及现有访问参数。
- 缩略图 endpoint 返回 `image/jpeg` 内容；不可用时沿用当前失败占位，不自动回退到原图。
- 分享密码、过期、下载开关和分享根目录边界由服务端统一判定，前端不复制权限逻辑。

## 可访问性

- 保留现有 `alt` 文本和键盘可达的预览入口。
- 缩略图仅优化传输体积，不改变原有预览/下载按钮的语义。
