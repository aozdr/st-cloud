# 测试用例

## P0 孤儿对象

| ID | 场景 | 期望 |
|---|---|---|
| P0-01 | 两个并发请求写同一规范对象，一次提交成功、一次失败 | 失败路径不删除已提交对象 |
| P0-02 | 两个请求均失败 | 候选进入 pending，宽限期前不删除，宽限期后安全删除 |
| P0-03 | 候选回收时出现 NORMAL `file_object` | 不删除对象 |
| P0-04 | 候选回收时存在有效 `file_node` 或活动上传会话 | 不删除对象并保留/恢复候选 |
| P0-05 | 归档、文本覆盖、编辑器回调提交失败 | 均走候选登记，不再立即删除规范路径 |

## Relay 序号

| ID | 场景 | 期望 |
|---|---|---|
| R-01 | `uploadPart` 失败后重试同一 seq | 不返回错误的已确认；可重试或明确终止 |
| R-02 | 跳过 committed+1 的 seq | 返回冲突，不推进序号 |
| R-03 | 已提交 seq 重复请求 | 幂等确认，不重复写入 |
| R-04 | body 读取/追加失败 | in-flight 释放，不能吞掉为成功 |

## Desktop

| ID | 场景 | 期望 |
|---|---|---|
| D-01 | 新建 relay 任务并暂停后恢复 | 元数据持久化，恢复只调用 relay chunk/finalize |
| D-02 | 旧 SQLite 缺少三列 | 自动补列，旧任务可读取 |
| D-03 | 应用重启后存在 relay uploading 任务 | 标记重新开始，不进入直传分支 |

## Share

| ID | 场景 | 期望 |
|---|---|---|
| S-01 | 正常分享图片胶卷 | 返回 JPEG 缩略图，不返回原图流 |
| S-02 | 密码错误、过期、禁止下载、节点越界 | 与现有分享授权一致地拒绝 |
| S-03 | 预览缩略图不存在 | 生成/缓存后返回缩略图 |
