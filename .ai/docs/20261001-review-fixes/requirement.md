# 需求

用户于 2026-10-01 明确要求解决本轮 review 的两项问题。用户场景为同时打开云盘文件页和文档页，以及先回收团队文件再删除团队空间。

A1：同源浏览器标签页使用完整最新令牌对，正常并发续期共用轮换结果，不因另一页使用旧 refresh 被误登出。
A2：退出/换账号/换服使旧结果失效，拒绝不能删除更新的共享会话；断网/5xx 保留可恢复凭据，Electron 继续由主进程轮换。
A3：团队空间软删除后，其已回收文件仍能按既有保留期由系统清理；用户列表、恢复与永久删除仍要求有效空间/成员权限，正常文件不能被定时清理。
A4：相关测试和类型检查通过，独立检查当前修订并记录真实证据。

边界：不处理正常文件的空间删除产品策略，不修改 HTTP/IPC 契约、数据库结构、原有物理删除事件机制或上传业务；不部署，不删除用户数据，不覆盖已有改动。不涉及页面/视觉设计。
异常：共享存储失败保留内存最新会话；暂时网络故障不强制退出；空间物理缺失不伪造管理员权限。
未决事项：无，用户已授权修复 review 中的具体缺陷。
