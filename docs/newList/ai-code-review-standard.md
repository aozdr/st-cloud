# AI代码Review输出标准

## 1. 文档目标

所有开发任务完成后，AI必须执行代码Review。

目标： - 检查代码质量 - 发现潜在问题 - 保证架构一致性 - 降低线上风险

-   是否符合项目架构
-   是否存在职责混乱
-   是否存在重复代码
-   是否合理复用已有能力

# 三、后端代码检查

检查：

## Controller层

-   是否只负责参数接收
-   是否存在业务逻辑

## Service层

-   业务逻辑是否合理
-   是否存在事务问题

## 数据访问层

-   SQL是否合理
-   是否存在慢查询风险

# 四、前端代码检查

检查：

-   组件职责
-   状态管理
-   是否重复实现
-   UI是否符合设计规范
-   是否存在性能问题

# 五、安全检查

必须检查：

-   权限校验
-   参数验证
-   SQL注入风险
-   越权访问
-   敏感数据泄露

# 六、性能检查

检查：

-   数据查询次数
-   大数据量处理
-   缓存使用
-   前端渲染性能

# 七、测试检查

确认：

-   是否有对应测试用例
-   是否覆盖关键流程
-   是否覆盖异常情况

# 输出要求

AI Review必须： 1. 不能只检查语法 2. 必须检查业务风险 3.
必须检查架构一致性 4. 必须给出可执行建议 5. 修改完成后重新Review
