# 输出要求

AI必须： 1. 开发前输出需求文档 2. 明确业务流程 3. 明确边界条件 4.
明确验收标准 5. 未确认需求前禁止直接编码

## 确认门禁（20260815 起）

-   需求文档产出后必须**经用户确认**（含遗留问题点逐项拍板）才能进入下一步
-   未经用户确认，不得进入影响分析 / 技术设计 / 编码等下游阶段

## 简洁性

-   直说事实与决策，禁止空话套话与互联网黑话（赋能/抓手/闭环/颗粒度/对齐 等）
-   能用表格/列表/短句表达的不用长段落；每段只说一件事
